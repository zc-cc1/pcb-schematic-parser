## Q1 为什么不用大模型(如赛会提供的 qwen3.7-plus)端到端解析?

**一句话**:95% 的权重在像素级结构精度上,大模型输出像素坐标不可靠,而 Token 越少分越高——我们零调用。

要点:
- 评分主体是 bbox 20px / pin 5px / 超图 soft F1 这类像素级硬指标,生成式模型给出稳定像素坐标的能力不足且不可审计;
- Token 赋分制:全队按消耗排序,越少越好,最低者满分区间;我们 token_usage=0,该 5% 按满分贡献;
- 全本地推理在 2 小时/30~50 例约束下没有排队与费用风险。
**依据**:赛题 PDF 评分细则;`agent.py` decision_log(token_usage 全 0);全代码无 LLM_* 引用(source_audit.md §2.2)。

## Q2 官方 74 分与本地 98.93 差距怎么解释?

**一句话**:口径不同——74 分来自含 2/3 黑盒(难例 60%)的官方评测,98.93 只是 13 页公开集的本地回放。

要点:
- 黑盒页的绘制风格/分辨率/密度无先验信息,泛化是主要差距;
- 我们以保守设计(漏连不连错)对抗难例,并保留 JunctionCNN 等增强;
- 旧版 8422=28.92 → 最终 74 的 +45 分提升来自电源出口/LED/IC 型号/实框/工程编号等修复(可逐条指)。
**依据**:defense_supplement.md §一.2;README.md:50;L18 manifest development_score=98.93。

## Q3 T 型、十字交叉节点怎么处理?

**一句话**:默认保守拆分、显式不确定,配合红点检测;学习型分类器已训练但默认关闭。

要点:
- 度≥4 结点保守拆分(split_four_way),T 型保守合并——把"连错"风险转为"漏连";
- 红色结点盘检测(面积/长宽比/填充率门控)辅助;
- 结点归并阶段凭硬证据恢复(见 Q4);
- JunctionCNN(6 通道双视角,4 旋转一致@0.95)在 v2 pilot,默认关——判错代价高于漏连。
**依据**:configs/wire_graph_v1.json:20 / wire_graph_v2.json;wire_graph.py junction_graph;source_audit.md §5.2、defense_supplement.md §四.1。

## Q4 断线、漏检怎么办?

**一句话**:图阶段只记录 gap 不乱接;修复阶段凭硬证据恢复,实测总分 +0.31 分。

要点:
- gap 合并需 learned mask 支持率≥0.8、共线±8°、且 gap 两侧不能各有一个 pin;
- 结点归并:60px 共线重合(±3°、垂距≤2px)或红点+95% 墨迹支持;
- 断线网放行导出:连通 0.569→0.576(+0.7pp),总分 +0.31 分——注意口径;
- 页 13 案例:32/28/17→46/13/3,F1 58.72%→85.19%。
**依据**:wire_segments.py:102-174;wire_graph_artifacts.py:116-117;docs/network_junction_reconciliation.md。

## Q5 pin 编号太小读不到怎么办?

**一句话**:条带 OCR(引线外端 30-50px 的 8px 字形)+ 密行重读 + 6 视角定向 OCR + 1000 型号引脚库,PinF1 0.031→0.549。

要点:
- 页级 OCR 看不到框外 26px 带的编号 → 以 pin 尖端为中心 44×20 条带,3/4/6× 双向读;
- 密排 IC 行把引线读成"—1/一4"的,只重读该字形自己的框;
- 定向补漏:缩放 2/3/4 × 旋转 0/90 六视角,≥2 视角@0.98 才采纳;
- 库映射:BoxICLibrary 1000 型号(EasyEDA 符号)+ STM32F103C8T6 引脚库(ST 数据表出处)。
**依据**:run_engineering_networks.py:26-27;pin_number_strip/pin_number_reread docstring;targeted_pin_ocr_v1.json。

## Q6 飞线(同一 net 的多个同名测试点)怎么识别?

**一句话**:同名非电源标签 ≥2 处逻辑合并,edges 输出零长度段;VCC/GND 除外,要过四道门。

要点:
- 飞线判定:同页同名标签多处、非 GND/VCC 族 → 合并为一个逻辑网,edges 每接点一条零长度段(与官方示例一致);
- 电源网合并四道门:单 tip 归属 / ≥3 独立视图同字形 / 无冲突拼写 / 无未决交叉,且绝不画物理长线。
**依据**:network_labels.py build_logical_networks;power_networks.py:95-168;赛题 PDF 附录一 §8。

## Q7 bbox 20px 怎么保证?两套口径是什么关系?

**一句话**:检测框是 CAD 单元外扩,用 40 页公开子集校准的 canonical 尺寸+中心偏移(达标率 0.905→1.000),另有 13 页的按页缩放(150/163→159/163)——两套独立实验、机制不同、同时生效但不可相乘。

要点:
- IC/LED 排除在 canonical 表外(IC 尺寸不固定,走形态学实框/LED 模板);
- 按页缩放解决"同一符号 23×58 与 40×16 两种画法";
- Name==key 约定同为 200 页 9186 组件统计(box 仅 .242 → 保留型号)。
**依据**:export_geometry.py:1-30;agent.py:988-994;adapter.py:28-64。

## Q8 两小时跑得完吗?

**一句话**:按 GPU 3 并发设计;CPU 单例实测约 2000 秒(官方示例页);官方机时未实测——如实回答,决赛前可申请复测。

要点:
- choose_workers:显存≥24GB → 3 并发;每例 wall_seconds 全程记录;
- 冒烟为 CPU 环境,官方 A800 预期分钟级(不复测不下结论)。
**依据**:agent.py:557-611;defense_supplement.md §五。

## Q9 结果的可信度/可复现性怎么保证?

**一句话**:逐文件 SHA256 manifest(249 项)+ 权重指纹锁定 + 预检 12 项资产 + 626 单测 + 构建期断言 + 全链审计日志。

要点:
- 任何权重/配置被替换会显式失败而非静默;
- 每阶段 try/except + remember() 冻结最近有效预测,失败只读本图工作目录恢复,绝不写空结果之外的猜测;
- 第 6 次评测 0 分教训 → overlay_check.py 构建期门禁。
**依据**:package_manifest.json;export_resilience.py;overlay_check.py:4-7;tests/ 计数。

## Q10 和现有开源方案/其他队相比,核心差异是什么?

**一句话**:别人堆模型,我们堆"纪律"——模型只产生候选,结论由证据体系给出;外加面向官方标注约定的统计校准。

**依据**:source_audit.md §6;docs/*.md;defense_slide_plan.md P6。
