# 术语速查与排错

## 先记住这些词

| 术语 | 通俗解释 | 常见误解 |
| --- | --- | --- |
| 像素 | 图像表格中的一个位置 | 彩色像素不只一个数 |
| 通道 | 同一位置记录的一类数值，如蓝色强度 | BGR和RGB顺序不同 |
| ROI | 只关心的一块区域 | 切片可能共享原图 |
| mask/掩膜 | 指定哪些位置被选中 | 常用单通道uint8 |
| 核 | 处理时查看的邻域或权重 | 越大不一定越好 |
| 阈值 | 进行取舍的数值界线 | 不同函数的阈值含义不同 |
| 轮廓 | 物体边界的一串点 | 不等于填满物体的掩膜 |
| 连通域 | 彼此邻接的一组前景像素 | 接触的两物体可能被算作一个 |
| 特征 | 为了比较或判断而提取的数值 | 特征不自动等于语义 |
| 单应矩阵 | 平面之间的透视坐标映射 | 不普遍适用于多深度场景 |
| 内点 | 符合估计模型的对应点 | 内点多仍需检查覆盖与误差 |
| FPS | 每秒帧数 | 播放FPS和处理FPS不同 |
| 精确率 | 检出的结果中有多少是真的 | 不是所有真实目标找回的比例 |
| 召回率 | 所有真实目标中找回多少 | 漏检越多一般越低 |
| IoU | 预测与真值的交集除以并集 | 是重合度，不是概率 |
| 训练/验证/测试 | 学习、选参数、最终考试 | 不应反复用最终测试集调参 |

## 按顺序排查

1. **输入。** 文件是否存在？图片读出是否None？视频有没有读到帧？
2. **数据。** 打印shape、dtype、最小值、最大值；检查宽高与通道。
3. **中间结果。** 原图、灰度、掩膜、轮廓分别保存，找到最先变错的一步。
4. **参数。** 一次改一个参数，用同一输入比较。
5. **假设。** 检查光照、尺度、接触、透视是否违反当前方法条件。

## 常见现象

| 现象 | 优先检查 | 处理方法 |
| --- | --- | --- |
| No module named cv2/numpy | 运行的Python与安装依赖的Python是否一致 | 用同一个解释器执行 `-m pip` 和脚本 |
| 找不到文件 | 工作目录、拼写、扩展名 | 用绝对路径或按本课Path方式定位 |
| cvtColor提示空输入 | 图片读取失败 | 先检查文件与解码结果，不要先改颜色参数 |
| 蓝红颠倒 | BGR与RGB混淆 | 需要给RGB工具显示时再明确转换 |
| 结果宽高反了 | 把shape直接传给resize | shape为高宽，尺寸参数为宽高 |
| 图片加亮后出现黑块 | uint8回绕 | 先转浮点/较大整数再clip，或使用适当饱和运算 |
| 拼接图片时报尺寸错误 | 通道数和高宽不一致 | 必要时灰度转BGR，统一对应尺寸 |
| threshold处理异常 | 输入类型或通道不合要求 | 本课阈值示例先转单通道uint8 |
| 模板匹配永远说有目标 | 总是取最大值却没拒绝规则 | 加入负样本与合理门槛 |
| 视频有文件却不能播放 | writer未打开、尺寸错、未release | 检查创建状态与每帧尺寸，正常释放资源 |
| 相机打不开 | 编号、权限、设备占用 | 先跑默认合成视频，再单独检查设备 |
| 中文文字画不出来 | putText内置字体不支持完整中文 | 本例图片标注用英文，讲义和注释保留中文 |
| 终端中文乱码 | 终端编码或查看器解码 | 文件均为UTF-8；可设 `$env:PYTHONIOENCODING='utf-8'` 后重试 |
| 分类测试好、实物很差 | 数据分布变化或数据泄漏 | 重新设计采集与独立验证，检查特征限制 |
