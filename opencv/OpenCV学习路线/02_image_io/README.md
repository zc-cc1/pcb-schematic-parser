# 第02周｜图像读写、颜色与基本运算

[返回总路线](../学习路线.md) · [上一周](../01_cpp_basics/README.md) · [下一周](../03_geometry/README.md)

## 本周要达到的结果

能可靠读取和保存图片；理解彩色转灰度会丢信息；会用掩膜选择区域；能区分普通加法与饱和加法。

前置基础：图像高宽、ROI与数据类型；本周仍使用Python。第1周C++完成后，请先读[语言衔接](../01_cpp_basics/与后续Python课程衔接.md)，补齐Python数组、切片与函数语法。

具体内容：读写检查、BGR/灰度、ROI、掩膜、饱和运算。

## 五次学习安排（约7.5小时）

| 次数 | 建议时长 | 具体任务 |
| --- | --- | --- |
| 第1次 | 60分钟 | 检查图像文件路径；用自己的话解释读取失败与空数组。 |
| 第2次 | 90分钟 | 观察BGR三个通道，运行灰度转换，比较彩色和灰度shape。 |
| 第3次 | 90分钟 | 画掩膜；做局部保留颜色，观察掩膜内外像素。 |
| 第4次 | 120分钟 | 比较加法与图像混合；完成ROI马赛克。 |
| 第5次 | 90分钟 | 换自己的图片复现；整理路径、通道、尺寸三个排错检查点。 |

时间是参考。一个概念解释不清，可以多用一次学习时段，不必为了赶周数跳过理解。

## 运行方法

先让终端位于总目录 `OpenCV学习路线`，再运行：

```powershell
python ./02_image_io/demo.py
python ./02_image_io/exercise_solution.py
```

如果当前已在本周文件夹，直接运行 `python demo.py` 和 `python exercise_solution.py`。
使用独立虚拟环境时，把 `python` 换成该环境的Python路径，详见[环境准备](../00_开始学习.md)。
代码按文件所在位置保存结果，所以从其他工作目录启动也能找到本周 `outputs`。
重新运行会覆盖相同名称的演示结果；自己的实验请另起文件名或先备份结果。
