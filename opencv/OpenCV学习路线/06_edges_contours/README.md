# 第06周｜边缘、轮廓与形状测量

[返回总路线](../学习路线.md) · [上一周](../05_threshold_morphology/README.md) · [下一周](../07_color_detection/README.md)

## 本周要达到的结果

能解释边缘与轮廓的区别；会计算包围盒、面积、周长、质心；能用顶点和圆度做简单分类。

前置基础：第5周二值图和前景，第3周坐标。

具体内容：Sobel、Canny、轮廓、面积、周长、质心。

## 五次学习安排（约7.5小时）

| 次数 | 建议时长 | 具体任务 |
| --- | --- | --- |
| 第1次 | 60分钟 | 从灰度突变理解边缘；运行Sobel并查看负梯度的处理。 |
| 第2次 | 90分钟 | 运行Canny，比较阈值组合，不把边缘当物体填充区。 |
| 第3次 | 90分钟 | 在二值图上寻找轮廓，理解返回值和外轮廓。 |
| 第4次 | 120分钟 | 计算面积、周长、质心和圆度；标注包围盒。 |
| 第5次 | 90分钟 | 完成三角形/四边形/圆形分类；记录缩放、旋转和噪声的影响。 |

时间是参考。一个概念解释不清，可以多用一次学习时段，不必为了赶周数跳过理解。

## 运行方法

先让终端位于总目录 `OpenCV学习路线`，再运行：

```powershell
python ./06_edges_contours/demo.py
python ./06_edges_contours/exercise_solution.py
```

如果当前已在本周文件夹，直接运行 `python demo.py` 和 `python exercise_solution.py`。
使用独立虚拟环境时，把 `python` 换成该环境的Python路径，详见[环境准备](../00_开始学习.md)。
代码按文件所在位置保存结果，所以从其他工作目录启动也能找到本周 `outputs`。
重新运行会覆盖相同名称的演示结果；自己的实验请另起文件名或先备份结果。
