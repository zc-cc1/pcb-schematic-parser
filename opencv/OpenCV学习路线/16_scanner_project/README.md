# 第16周｜项目二：文档扫描与结课

[返回总路线](../学习路线.md) · [上一周](../15_inspection_project/README.md) · [结课与后续方向](../结课与后续方向.md)

## 本周要达到的结果

能自动寻找主要四边形；理解四点顺序；完成透视拉正与文档二值化；能明确报告无法扫描而不是输出伪结果。

前置基础：第3周透视、第5周阈值、第6周轮廓、第15周项目验证。

具体内容：轮廓四边形、角点排序、透视拉正、失败处理、验收。

## 五次学习安排（约7.5小时）

| 次数 | 建议时长 | 具体任务 |
| --- | --- | --- |
| 第1次 | 60分钟 | 梳理扫描器需求与前提，先对合成斜拍纸张测试。 |
| 第2次 | 90分钟 | 用边缘和轮廓筛出大凸四边形，保存检测过程。 |
| 第3次 | 90分钟 | 排序四角并估计输出宽高，透视拉正。 |
| 第4次 | 120分钟 | 做文档二值化并添加失败提示；运行空白和裁切反例。 |
| 第5次 | 90分钟 | 整理两个结课项目；用真实照片验收并完成结课自测。 |

时间是参考。一个概念解释不清，可以多用一次学习时段，不必为了赶周数跳过理解。

## 阅读与实践顺序

1. 阅读[讲义](讲义.md)，边看边在纸上写出小例子的结果。
2. 运行[主演示](demo.py)，逐张对照讲义中的输出。
3. 打开代码，跟着 `main()` 找到“输入→处理→保存”。每次只修改一个参数。
4. 先做[练习](练习.md)，再查看[参考答案](参考答案.md)和[可运行答案](exercise_solution.py)。
5. 填写[学习记录](学习记录.md)，通过下面的验收再继续。

## 运行方法

先让终端位于总目录 `OpenCV学习路线`，再运行：

```powershell
python ./16_scanner_project/demo.py
python ./16_scanner_project/exercise_solution.py
```

如果当前已在本周文件夹，直接运行 `python demo.py` 和 `python exercise_solution.py`。
使用独立虚拟环境时，把 `python` 换成该环境的Python路径，详见[环境准备](../00_开始学习.md)。
代码按文件所在位置保存结果，所以从其他工作目录启动也能找到本周 `outputs`。
重新运行会覆盖相同名称的演示结果；自己的实验请另起文件名或先备份结果。

## 预期现象与验收

输出斜拍图、边缘图、绿色四边形、拉正彩色文档和黑白文档；空白图应明确失败；裁切反例用于观察误识别或拒绝行为。

- [ ] 能独立运行主例，找到输出图片和 `metrics.json`。
- [ ] 能解释本周重点：轮廓四边形、角点排序、透视拉正、失败处理、验收。
- [ ] 已完成练习，记录至少一组参数变化的输入、输出和原因。
- [ ] 不看答案也能口头回答参考答案中的三道自测题。
- [ ] 能说出一种会让本周方法失败的输入，并说明下一步如何检查。

所有默认输入由代码生成，不需要下载素材。输出图片可用系统图片查看器打开。
