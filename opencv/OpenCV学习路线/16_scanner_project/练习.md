# 第16周练习｜项目二：文档扫描与结课

[返回本周计划](README.md)

## 先做，再看答案

1. 独立写出扫描器六步流程。
2. 运行正常、空白、裁切用例并核对是否应被接受。
3. 收集5张纸张照片和3张非纸张图片，逐张标记绿框是否正确。
4. 写结课报告，说明两个项目最容易失败的三种情况。

## 本周可运行参考实验

`exercise_solution.py` 提供本周核心编程练习的可运行参考，不代替你对其余观察题与口算题的解释。运行前先预测结果，再比较输出的 `exercise_*.png` 与可能生成的 `exercise_metrics.json`。

## 需要留下的学习证据

- 一份你自己修改过的代码，例如另存为 `my_practice.py`，避免覆盖原例。
- 至少两张对照图，文件名包含参数或条件。
- 在[学习记录](学习记录.md)写下“我先预测什么、实际发生什么、为什么不同”。
- 用自己的话解释一个失败场景，并提出可以检验的改进方向。

完成后查看[参考答案](参考答案.md)。观察实验不保证只有唯一参数答案，要看你是否有证据支持结论。
