# 第01周｜Python 与 NumPy：读懂一张图

[返回总路线](../../学习路线.md) · [环境准备](../../00_开始学习.md) · [下一周](../../02_image_io/README.md)

## 本周要达到的结果

能解释变量、循环与函数；能区分像素坐标和数组索引；能用切片修改区域；能解释 uint8 溢出和 copy 的作用。

前置基础：无需 OpenCV 基础；会创建文件夹、打开终端即可。Python 完全零基础时，本周允许拆成两周。

具体内容：变量、循环、函数、数组、坐标、切片与数据类型。

## 运行方法

先让终端位于总目录 `OpenCV学习路线`，再运行：

```powershell
python ./历史版本/01_python_numpy/demo.py
python ./历史版本/01_python_numpy/exercise_solution.py
```

如果当前已在本周文件夹，直接运行 `python demo.py` 和 `python exercise_solution.py`。
使用独立虚拟环境时，把 `python` 换成该环境的Python路径，详见[环境准备](../../00_开始学习.md)。
代码按文件所在位置保存结果，所以从其他工作目录启动也能找到本周 `outputs`。
重新运行会覆盖相同名称的演示结果；自己的实验请另起文件名或先备份结果。
