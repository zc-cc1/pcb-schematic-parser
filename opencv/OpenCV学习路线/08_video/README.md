# 第08周｜视频处理与逐帧流水线

[返回总路线](../学习路线.md) · [上一周](../07_color_detection/README.md) · [下一周](../09_template/README.md)

## 本周要达到的结果

会读写视频并检查成功状态；区分视频帧率与处理速度；知道资源释放的重要性；能把单图检测放进逐帧循环。

前置基础：第7周单张图片颜色检测，Python while、if、try/finally。

具体内容：VideoCapture/Writer、帧率、资源释放、视频标注。

## 五次学习安排（约7.5小时）

| 次数 | 建议时长 | 具体任务 |
| --- | --- | --- |
| 第1次 | 60分钟 | 理解帧、分辨率、帧率；生成80帧测试视频。 |
| 第2次 | 90分钟 | 读取视频并检查ret；解释何时结束循环。 |
| 第3次 | 90分钟 | 把颜色检测放到逐帧循环，写出标注视频。 |
| 第4次 | 120分钟 | 学习finally释放资源；可选手动运行摄像头模式。 |
| 第5次 | 90分钟 | 每秒抽取一帧；核对帧索引、时长与输出数量。 |

时间是参考。一个概念解释不清，可以多用一次学习时段，不必为了赶周数跳过理解。

## 阅读与实践顺序

1. 阅读[讲义](讲义.md)，边看边在纸上写出小例子的结果。
2. 运行[主演示](demo.py)，逐张对照讲义中的输出。
3. 打开代码，跟着 `main()` 找到“输入→处理→保存”。每次只修改一个参数。
4. 先做[练习](练习.md)，再查看[参考答案](参考答案.md)和[可运行答案](exercise_solution.py)。
5. 填写[学习记录](学习记录.md)，通过下面的验收再继续。

## 运行方法

先让终端位于总目录 `OpenCV学习路线`，再运行：

```powershell
python ./08_video/demo.py
python ./08_video/exercise_solution.py
```

如果当前已在本周文件夹，直接运行 `python demo.py` 和 `python exercise_solution.py`。
使用独立虚拟环境时，把 `python` 换成该环境的Python路径，详见[环境准备](../00_开始学习.md)。
代码按文件所在位置保存结果，所以从其他工作目录启动也能找到本周 `outputs`。
重新运行会覆盖相同名称的演示结果；自己的实验请另起文件名或先备份结果。
