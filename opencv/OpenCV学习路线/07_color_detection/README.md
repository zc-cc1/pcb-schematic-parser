# 第07周｜颜色识别与目标计数

[返回总路线](../学习路线.md) · [上一周](../06_edges_contours/README.md) · [下一周](../08_video/README.md)

## 本周要达到的结果

理解HSV三个分量；会提取红色双区间；能排除背景标签和小噪声；能用亮度实验解释漏检。

前置基础：第2周颜色与掩膜，第5周形态学，第6周对象与面积。

具体内容：HSV、红色双区间、连通域、面积筛选、误检漏检。

## 五次学习安排（约7.5小时）

| 次数 | 建议时长 | 具体任务 |
| --- | --- | --- |
| 第1次 | 60分钟 | 把BGR转换为HSV，读几个已知颜色像素。 |
| 第2次 | 90分钟 | 画出红色跨越色相首尾的关系，合并两张掩膜。 |
| 第3次 | 90分钟 | 用连通域提取物体，读取面积和中心，跳过背景。 |
| 第4次 | 120分钟 | 用面积筛选去掉小红点；比较轮廓面积和像素面积。 |
| 第5次 | 90分钟 | 做三个亮度实验；写出假设、漏检原因和改进方向。 |

时间是参考。一个概念解释不清，可以多用一次学习时段，不必为了赶周数跳过理解。

## 运行方法

先让终端位于总目录 `OpenCV学习路线`，再运行：

```powershell
python ./07_color_detection/demo.py
python ./07_color_detection/exercise_solution.py
```

如果当前已在本周文件夹，直接运行 `python demo.py` 和 `python exercise_solution.py`。
使用独立虚拟环境时，把 `python` 换成该环境的Python路径，详见[环境准备](../00_开始学习.md)。
代码按文件所在位置保存结果，所以从其他工作目录启动也能找到本周 `outputs`。
重新运行会覆盖相同名称的演示结果；自己的实验请另起文件名或先备份结果。
