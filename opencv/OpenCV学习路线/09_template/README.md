# 第09周｜模板匹配与相似度

[返回总路线](../学习路线.md) · [上一周](../08_video/README.md) · [下一周](../10_features/README.md)

## 本周要达到的结果

理解滑窗匹配与响应图；能正确解释最大匹配分数；知道模板大小与输出形状关系；完成多尺度搜索。

前置基础：第3周缩放、第4周相似度数值与实验控制。

具体内容：滑窗、响应图、非恒定模板、阈值、多尺度。

## 五次学习安排（约7.5小时）

| 次数 | 建议时长 | 具体任务 |
| --- | --- | --- |
| 第1次 | 60分钟 | 用纸片在大图上滑动的比喻理解模板匹配。 |
| 第2次 | 90分钟 | 运行单模板定位，核对左上角坐标与响应图尺寸。 |
| 第3次 | 90分钟 | 比较不同匹配方法的分数方向；理解置信度限制。 |
| 第4次 | 120分钟 | 把目标放大1.5倍，观察单尺度失败，再搜索多个尺度。 |
| 第5次 | 90分钟 | 加入相似干扰物和无目标图，记录误检，设计拒绝规则。 |

时间是参考。一个概念解释不清，可以多用一次学习时段，不必为了赶周数跳过理解。

## 阅读与实践顺序

1. 阅读[讲义](讲义.md)，边看边在纸上写出小例子的结果。
2. 运行[主演示](demo.py)，逐张对照讲义中的输出。
3. 打开代码，跟着 `main()` 找到“输入→处理→保存”。每次只修改一个参数。
4. 先做[练习](练习.md)，再查看[参考答案](参考答案.md)和[可运行答案](exercise_solution.py)。
5. 填写[学习记录](学习记录.md)，通过下面的验收再继续。

## 运行方法

先让终端位于总目录 `OpenCV学习路线`，再运行：

```powershell
python ./09_template/demo.py
python ./09_template/exercise_solution.py
```

如果当前已在本周文件夹，直接运行 `python demo.py` 和 `python exercise_solution.py`。
使用独立虚拟环境时，把 `python` 换成该环境的Python路径，详见[环境准备](../00_开始学习.md)。
代码按文件所在位置保存结果，所以从其他工作目录启动也能找到本周 `outputs`。
重新运行会覆盖相同名称的演示结果；自己的实验请另起文件名或先备份结果。
