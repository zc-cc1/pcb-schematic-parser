# 第04周｜噪声、滤波与对比度

[返回总路线](../学习路线.md) · [上一周](../03_geometry/README.md) · [下一周](../05_threshold_morphology/README.md)

## 本周要达到的结果

能区分高斯噪声与椒盐噪声；能解释滤波核；会比较高斯和中值滤波；理解增强对比度与去噪的区别。

前置基础：第1～3周：类型转换、灰度、区域。

具体内容：均值/高斯/中值滤波、直方图、CLAHE。

## 五次学习安排（约7.5小时）

| 次数 | 建议时长 | 具体任务 |
| --- | --- | --- |
| 第1次 | 60分钟 | 看干净图与两种带噪图；描述噪声长什么样。 |
| 第2次 | 90分钟 | 用3×3小表手算均值和中值，理解邻域。 |
| 第3次 | 90分钟 | 运行高斯与中值滤波，比较边缘和残余噪声。 |
| 第4次 | 120分钟 | 学习直方图与CLAHE，观察低对比度图。 |
| 第5次 | 90分钟 | 比较四种核大小，记录MSE和可见细节，选择有依据的参数。 |

时间是参考。一个概念解释不清，可以多用一次学习时段，不必为了赶周数跳过理解。

## 运行方法

先让终端位于总目录 `OpenCV学习路线`，再运行：

```powershell
python ./04_filtering/demo.py
python ./04_filtering/exercise_solution.py
```

如果当前已在本周文件夹，直接运行 `python demo.py` 和 `python exercise_solution.py`。
使用独立虚拟环境时，把 `python` 换成该环境的Python路径，详见[环境准备](../00_开始学习.md)。
代码按文件所在位置保存结果，所以从其他工作目录启动也能找到本周 `outputs`。
重新运行会覆盖相同名称的演示结果；自己的实验请另起文件名或先备份结果。
