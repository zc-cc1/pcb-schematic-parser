# 第11周｜运动检测与光流

[返回总路线](../学习路线.md) · [上一周](../10_features/README.md) · [下一周](../12_calibration/README.md)

## 本周要达到的结果

区分帧差、背景建模和光流；能过滤光流失败点；能解释光照和相机运动的影响；知道像素位移不等于实际速度。

前置基础：第8周视频帧、第6周角点/边缘概念、第10周对应点。

具体内容：帧差、背景模型、稀疏光流、状态过滤、相机运动。

## 五次学习安排（约7.5小时）

| 次数 | 建议时长 | 具体任务 |
| --- | --- | --- |
| 第1次 | 60分钟 | 生成前后两帧，手算物体移动方向与距离。 |
| 第2次 | 90分钟 | 运行帧差，观察旧位置和新位置都有响应。 |
| 第3次 | 90分钟 | 先学习空背景再提取前景，理解模型更新。 |
| 第4次 | 120分钟 | 跟踪角点并画运动箭头，读取status。 |
| 第5次 | 90分钟 | 运行仅改变光照的反例；为真实视频写适用条件说明。 |

时间是参考。一个概念解释不清，可以多用一次学习时段，不必为了赶周数跳过理解。

## 运行方法

先让终端位于总目录 `OpenCV学习路线`，再运行：

```powershell
python ./11_motion/demo.py
python ./11_motion/exercise_solution.py
```

如果当前已在本周文件夹，直接运行 `python demo.py` 和 `python exercise_solution.py`。
使用独立虚拟环境时，把 `python` 换成该环境的Python路径，详见[环境准备](../00_开始学习.md)。
代码按文件所在位置保存结果，所以从其他工作目录启动也能找到本周 `outputs`。
重新运行会覆盖相同名称的演示结果；自己的实验请另起文件名或先备份结果。
