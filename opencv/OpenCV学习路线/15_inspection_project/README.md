# 第15周｜项目一：零件计数与缺陷检测

[返回总路线](../学习路线.md) · [上一周](../14_ml/README.md) · [下一周](../16_scanner_project/README.md)

## 本周要达到的结果

能把需求写成可验证条件；组织可复用检测函数；把参数与业务假设记录到报告；系统保存失败用例。

前置基础：第5～7周的分割、形状测量和评价；第14周实验数据划分意识。

具体内容：需求约束、模块化、阈值配置、批量测试、报告。

## 五次学习安排（约7.5小时）

| 次数 | 建议时长 | 具体任务 |
| --- | --- | --- |
| 第1次 | 60分钟 | 写需求：暗背景、亮圆形零件、互不接触；规定什么叫缺陷。 |
| 第2次 | 90分钟 | 实现灰度→阈值→轮廓→面积过滤的计数链。 |
| 第3次 | 90分钟 | 增加圆度缺陷判定，保存每个对象的特征和框。 |
| 第4次 | 120分钟 | 运行正常、缺口、亮背景三个用例，记录通过与失败。 |
| 第5次 | 90分钟 | 用自有图片检验假设，提交结果图、JSON报告和局限说明。 |

时间是参考。一个概念解释不清，可以多用一次学习时段，不必为了赶周数跳过理解。

## 阅读与实践顺序

1. 阅读[讲义](讲义.md)，边看边在纸上写出小例子的结果。
2. 运行[主演示](demo.py)，逐张对照讲义中的输出。
3. 打开代码，跟着 `main()` 找到“输入→处理→保存”。每次只修改一个参数。
4. 先做[练习](练习.md)，再查看[参考答案](参考答案.md)和[可运行答案](exercise_solution.py)。
5. 填写[学习记录](学习记录.md)，通过下面的验收再继续。

## 运行方法

先让终端位于总目录 `OpenCV学习路线`，再运行：

```powershell
python ./15_inspection_project/demo.py
python ./15_inspection_project/exercise_solution.py
```

如果当前已在本周文件夹，直接运行 `python demo.py` 和 `python exercise_solution.py`。
使用独立虚拟环境时，把 `python` 换成该环境的Python路径，详见[环境准备](../00_开始学习.md)。
代码按文件所在位置保存结果，所以从其他工作目录启动也能找到本周 `outputs`。
重新运行会覆盖相同名称的演示结果；自己的实验请另起文件名或先备份结果。

默认场景6个零件，1个缺口件标成NG，其余OK；亮背景用例故意违反前提，应被记录为失败，不能为了报告好看删掉它。

- [ ] 能独立运行主例，找到输出图片和 `metrics.json`。
- [ ] 能解释本周重点：需求约束、模块化、阈值配置、批量测试、报告。
- [ ] 已完成练习，记录至少一组参数变化的输入、输出和原因。
- [ ] 不看答案也能口头回答参考答案中的三道自测题。
- [ ] 能说出一种会让本周方法失败的输入，并说明下一步如何检查。

所有默认输入由代码生成，不需要下载素材。输出图片可用系统图片查看器打开。
