# 官方参考资料

本课程按OpenCV 4.x常用Python接口编写，在4.12.0环境执行验证。4.x在线文档可能指向后续小版本，查询时注意版本标签；旧版2.x/3.x文章的接口返回值不一定适用。

资料核对日期：2026-09-18。以下链接来自官方项目与文档，讲义本身可离线阅读。

| 用途 | 官方资料 | 阅读建议 |
| --- | --- | --- |
| 完整主题入口 | [OpenCV-Python Tutorials](https://docs.opencv.org/4.x/d6/d00/tutorial_py_root.html) | 按周主题进入对应章节，不必从头啃完 |
| 颜色、滤波、轮廓等 | [Image Processing in OpenCV](https://docs.opencv.org/4.12.0/d2/d96/tutorial_py_table_of_contents_imgproc.html) | 重点核对输入类型、参数和返回值 |
| 三种阈值 | [Image Thresholding](https://docs.opencv.org/4.12.0/d7/d4d/tutorial_py_thresholding.html) | 对照第5周的光照实验 |
| ORB | [ORB](https://docs.opencv.org/4.x/d1/d89/tutorial_py_orb.html) | 先区分关键点和描述子，再看实现细节 |
| 标定与相机模型 | [Camera Calibration and 3D Reconstruction](https://docs.opencv.org/4.x/d9/d0c/group__calib3d.html) | 第12周先看K、畸变和函数参数，推导可后补 |
| 分水岭 | [Watershed](https://docs.opencv.org/4.x/d3/db4/tutorial_py_watershed.html) | 着重理解marker的含义与数据类型 |
| Python安装包 | [opencv-python官方仓库说明](https://github.com/opencv/opencv-python) | 核对标准包、contrib与headless的区别 |

用资料解决一个明确问题，例如“返回值第一个是什么”“H范围取决于哪种数据类型”。读完回到本课的小实验验证，比连续浏览大量互不衔接的教程更容易建立稳定理解。
