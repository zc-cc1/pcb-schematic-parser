# 第05周｜二值化与形态学

[返回总路线](../学习路线.md) · [上一周](../04_filtering/README.md) · [下一周](../06_edges_contours/README.md)

## 本周要达到的结果

能区分三种阈值；理解前景方向；能选择开运算清噪和闭运算填洞；知道结构元素会改变物体形状。

前置基础：第2周掩膜，第4周滤波与噪声。

具体内容：固定/自适应/Otsu 阈值、腐蚀膨胀、开闭运算。

## 五次学习安排（约7.5小时）

| 次数 | 建议时长 | 具体任务 |
| --- | --- | --- |
| 第1次 | 60分钟 | 对五个灰度值手算固定阈值；观察反向阈值。 |
| 第2次 | 90分钟 | 比较固定阈值和Otsu，记录自动选出的阈值。 |
| 第3次 | 90分钟 | 学习局部阈值，处理明暗不均的纸张。 |
| 第4次 | 120分钟 | 手画腐蚀膨胀效果，运行开闭运算。 |
| 第5次 | 90分钟 | 改变blockSize和C，做六组实验，解释字变粗或变细的原因。 |

时间是参考。一个概念解释不清，可以多用一次学习时段，不必为了赶周数跳过理解。

## 阅读与实践顺序

1. 阅读[讲义](讲义.md)，边看边在纸上写出小例子的结果。

## 运行方法

先让终端位于总目录 `OpenCV学习路线`，再运行：

```powershell
python ./05_threshold_morphology/demo.py
python ./05_threshold_morphology/exercise_solution.py
```

如果当前已在本周文件夹，直接运行 `python demo.py` 和 `python exercise_solution.py`。
使用独立虚拟环境时，把 `python` 换成该环境的Python路径，详见[环境准备](../00_开始学习.md)。
代码按文件所在位置保存结果，所以从其他工作目录启动也能找到本周 `outputs`。
重新运行会覆盖相同名称的演示结果；自己的实验请另起文件名或先备份结果。
