# 第13周｜分开粘连目标：分水岭

[返回总路线](../学习路线.md) · [上一周](../12_calibration/README.md) · [下一周](../14_ml/README.md)

## 本周要达到的结果

理解距离变换的几何含义；能构造前景种子、背景和未知区；理解分水岭标签值；知道种子数量如何影响分割。

前置基础：第5周形态学、第7周连通域。

具体内容：距离变换、种子、未知区、分水岭、分割评价。

## 五次学习安排（约7.5小时）

| 次数 | 建议时长 | 具体任务 |
| --- | --- | --- |
| 第1次 | 60分钟 | 用两个粘连圆测试连通域，说明为什么只有一个对象。 |
| 第2次 | 90分钟 | 观察距离变换，比较圆中心与边界的值。 |
| 第3次 | 90分钟 | 从距离图生成种子，观察阈值如何改变种子数。 |
| 第4次 | 120分钟 | 构建int32标记并运行分水岭，解释-1、0、1、2。 |
| 第5次 | 90分钟 | 比较四种种子比例，记录分割数量；说明真实粘连场景限制。 |

时间是参考。一个概念解释不清，可以多用一次学习时段，不必为了赶周数跳过理解。

## 运行方法

先让终端位于总目录 `OpenCV学习路线`，再运行：

```powershell
python ./13_segmentation/demo.py
python ./13_segmentation/exercise_solution.py
```

如果当前已在本周文件夹，直接运行 `python demo.py` 和 `python exercise_solution.py`。
使用独立虚拟环境时，把 `python` 换成该环境的Python路径，详见[环境准备](../00_开始学习.md)。
代码按文件所在位置保存结果，所以从其他工作目录启动也能找到本周 `outputs`。
重新运行会覆盖相同名称的演示结果；自己的实验请另起文件名或先备份结果。
