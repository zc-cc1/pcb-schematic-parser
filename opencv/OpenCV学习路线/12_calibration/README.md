# 第12周｜相机成像与标定入门

[返回总路线](../学习路线.md) · [上一周](../11_motion/README.md) · [下一周](../13_segmentation/README.md)

## 本周要达到的结果

理解内参、外参与畸变；知道棋盘内角点与格子数的区别；能解读重投影误差；能按流程采集真实标定照片。

前置基础：第3周投影与坐标，第10周几何误差；愿意理解简单比例关系。

具体内容：内参、畸变、棋盘角点、重投影误差、真实采集。

## 五次学习安排（约7.5小时）

| 次数 | 建议时长 | 具体任务 |
| --- | --- | --- |
| 第1次 | 60分钟 | 用小孔成像理解近大远小；区分像素与米。 |
| 第2次 | 90分钟 | 运行理想模拟标定，比较真实K与估计K。 |
| 第3次 | 90分钟 | 增加0.2、1.0像素角点噪声，观察误差与参数变化。 |
| 第4次 | 120分钟 | 阅读真实标定脚本；准备9×6内角点棋盘和拍摄清单。 |
| 第5次 | 90分钟 | 有设备则采集15～25张照片标定；无设备则完成模拟实验与采集方案。 |

时间是参考。一个概念解释不清，可以多用一次学习时段，不必为了赶周数跳过理解。

## 阅读与实践顺序

1. 阅读[讲义](讲义.md)，边看边在纸上写出小例子的结果。
2. 运行[主演示](demo.py)，逐张对照讲义中的输出。
3. 打开代码，跟着 `main()` 找到“输入→处理→保存”。每次只修改一个参数。
4. 先做[练习](练习.md)，再查看[参考答案](参考答案.md)和[可运行答案](exercise_solution.py)。
5. 填写[学习记录](学习记录.md)，通过下面的验收再继续。

## 运行方法

先让终端位于总目录 `OpenCV学习路线`，再运行：

```powershell
python ./12_calibration/demo.py
python ./12_calibration/exercise_solution.py
```

如果当前已在本周文件夹，直接运行 `python demo.py` 和 `python exercise_solution.py`。
使用独立虚拟环境时，把 `python` 换成该环境的Python路径，详见[环境准备](../00_开始学习.md)。
代码按文件所在位置保存结果，所以从其他工作目录启动也能找到本周 `outputs`。
重新运行会覆盖相同名称的演示结果；自己的实验请另起文件名或先备份结果。
