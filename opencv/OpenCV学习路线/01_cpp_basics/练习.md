# 第一周C++练习

先独立完成，再看[参考答案](参考答案.md)。修改自己的代码可另存文件，保留原始示例便于对照。

1. 修改basics，让循环只打印大于等于20的数字；把add(3,5)换成add(-2,7)，先写预期值。
2. 创建高120、宽200的CV_8UC3黑图，把x=10、y=20、宽60、高40区域填绿。打印该区域内部一个像素的三个通道。
3. 分别使用Mat赋值、ROI和clone创建对象，修改其中一个像素。记录哪些图会同步变化，哪些不会。
4. 写出a=250、b=10时int sum、8位缩窄、饱和转换的三个结果；解释为什么不能把Python数组加法规则直接搬过来。
5. 从空文件创建160×240棋盘，每格40×40；统计纯白像素并与口算比较。把白格减亮50，黑格仍保持0。
6. 挑战：写一个函数，接受正整数格子边长、行数、列数，返回棋盘；拒绝小于等于0的参数。若总格数为奇数且左上角白，白格数是多少？

交付：你的.cpp、一组结果图、一次失败排查记录和五句话的本周总结。练习5的可运行参考是[exercise_solution.cpp](exercise_solution.cpp)，其余题的思路见参考答案。
