# 第03周｜缩放、旋转与透视变换

[返回总路线](../学习路线.md) · [上一周](../02_image_io/README.md) · [下一周](../04_filtering/README.md)

## 本周要达到的结果

能正确传入宽高；能选择缩放插值；理解旋转裁切；能用对应四点做平面透视校正。

前置基础：第1～2周：数组、宽高、图像读写。

具体内容：宽高顺序、插值、仿射矩阵、四点透视。

## 五次学习安排（约7.5小时）

| 次数 | 建议时长 | 具体任务 |
| --- | --- | --- |
| 第1次 | 60分钟 | 观察网格图；缩放到一半，核对输出shape。 |
| 第2次 | 90分钟 | 对比最近邻、线性、面积插值；描述锯齿和模糊。 |
| 第3次 | 90分钟 | 改变旋转角度与中心；观察角落为何被裁掉。 |
| 第4次 | 120分钟 | 用四个角点制造倾斜，再执行逆变换。 |
| 第5次 | 90分钟 | 实现旋转后扩大画布；解释为什么逆变换不能完全还原。 |

时间是参考。一个概念解释不清，可以多用一次学习时段，不必为了赶周数跳过理解。

## 运行方法

先让终端位于总目录 `OpenCV学习路线`，再运行：

```powershell
python ./03_geometry/demo.py
python ./03_geometry/exercise_solution.py
```

如果当前已在本周文件夹，直接运行 `python demo.py` 和 `python exercise_solution.py`。
使用独立虚拟环境时，把 `python` 换成该环境的Python路径，详见[环境准备](../00_开始学习.md)。
代码按文件所在位置保存结果，所以从其他工作目录启动也能找到本周 `outputs`。
重新运行会覆盖相同名称的演示结果；自己的实验请另起文件名或先备份结果。
