# 第10周｜特征匹配与图像对齐

[返回总路线](../学习路线.md) · [上一周](../09_template/README.md) · [下一周](../11_motion/README.md)

## 本周要达到的结果

区分关键点与描述子；掌握ORB匹配流程；能解释比率筛选和RANSAC各自作用；理解平面对齐的限制。

前置基础：第3周透视变换，第9周匹配与相似度；理解二维点和列表。

具体内容：ORB、描述子、汉明距离、比率筛选、RANSAC。

## 五次学习安排（约7.5小时）

| 次数 | 建议时长 | 具体任务 |
| --- | --- | --- |
| 第1次 | 60分钟 | 观察ORB关键点，理解位置与局部外观信息。 |
| 第2次 | 90分钟 | 匹配描述子，解释汉明距离和两位候选。 |
| 第3次 | 90分钟 | 改变比率门槛，比较保留数量与可靠程度。 |
| 第4次 | 120分钟 | 用RANSAC估计单应矩阵，画出内点匹配。 |
| 第5次 | 90分钟 | 对齐图片并测量角点误差；用纯色图测试失败提示。 |

时间是参考。一个概念解释不清，可以多用一次学习时段，不必为了赶周数跳过理解。

## 阅读与实践顺序

1. 阅读[讲义](讲义.md)，边看边在纸上写出小例子的结果。
2. 运行[主演示](demo.py)，逐张对照讲义中的输出。
3. 打开代码，跟着 `main()` 找到“输入→处理→保存”。每次只修改一个参数。
4. 先做[练习](练习.md)，再查看[参考答案](参考答案.md)和[可运行答案](exercise_solution.py)。
5. 填写[学习记录](学习记录.md)，通过下面的验收再继续。

## 运行方法

先让终端位于总目录 `OpenCV学习路线`，再运行：

```powershell
python ./10_features/demo.py
python ./10_features/exercise_solution.py
```

如果当前已在本周文件夹，直接运行 `python demo.py` 和 `python exercise_solution.py`。
使用独立虚拟环境时，把 `python` 换成该环境的Python路径，详见[环境准备](../00_开始学习.md)。
代码按文件所在位置保存结果，所以从其他工作目录启动也能找到本周 `outputs`。
重新运行会覆盖相同名称的演示结果；自己的实验请另起文件名或先备份结果。
