# 第14周｜从手写规则到机器学习

[返回总路线](../学习路线.md) · [上一周](../13_segmentation/README.md) · [下一周](../15_inspection_project/README.md)

## 本周要达到的结果

理解特征向量与分类器；会训练OpenCV SVM；区分训练集和测试集；能读混淆矩阵并识别分布变化。

前置基础：第4周梯度/噪声，第6周特征，第7周误检与漏检。

具体内容：HOG、SVM、训练/测试分离、混淆矩阵、数据偏差。

## 五次学习安排（约7.5小时）

| 次数 | 建议时长 | 具体任务 |
| --- | --- | --- |
| 第1次 | 60分钟 | 回顾手工规则分类；理解把一张图变成一排特征。 |
| 第2次 | 90分钟 | 学习HOG的梯度方向统计，核对输入尺寸。 |
| 第3次 | 90分钟 | 生成独立训练和测试样本，训练线性SVM。 |
| 第4次 | 120分钟 | 读准确率和混淆矩阵，逐格解释含义。 |
| 第5次 | 90分钟 | 执行旋转测试，写明高测试分数为何不代表真实泛化能力。 |

时间是参考。一个概念解释不清，可以多用一次学习时段，不必为了赶周数跳过理解。

## 运行方法

先让终端位于总目录 `OpenCV学习路线`，再运行：

```powershell
python ./14_ml/demo.py
python ./14_ml/exercise_solution.py
```

如果当前已在本周文件夹，直接运行 `python demo.py` 和 `python exercise_solution.py`。
使用独立虚拟环境时，把 `python` 换成该环境的Python路径，详见[环境准备](../00_开始学习.md)。
代码按文件所在位置保存结果，所以从其他工作目录启动也能找到本周 `outputs`。
重新运行会覆盖相同名称的演示结果；自己的实验请另起文件名或先备份结果。
