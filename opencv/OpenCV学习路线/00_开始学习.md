# 环境准备与运行方法（第2～16周Python）

第一周已改为C++，请先看[第一周C++环境配置](01_cpp_basics/环境配置与运行.md)。以下Python命令不能用来编译C++。

## 1. 先确认自己在哪个目录

本机课程位置为 `C:/Users/zc/Desktop/vision/opencv/OpenCV学习路线`。
在资源管理器进入该文件夹，在地址栏输入 `powershell` 并回车，终端就会以这里作为工作目录。

也可以在已有PowerShell中运行：

```powershell
Set-Location 'C:/Users/zc/Desktop/vision/opencv/OpenCV学习路线'
```

复制到其他电脑后请替换路径。文档链接使用相对路径，所以保留整个文件夹结构即可移动。

## 2. 这台电脑已经能直接运行

课程制作时确认本机有Python 3.13.5、OpenCV 4.12.0和NumPy 2.1.3。

```powershell
python -c "import sys, cv2, numpy; print(sys.version); print(cv2.__version__); print(numpy.__version__)"
python ./02_image_io/demo.py
```

若能运行，就从第2周开始。无需先重新安装，也无需改变已有环境。

## 3. 在新电脑上安装，或希望使用独立环境

准备Python 3.11～3.13；本课程实际验证的是3.13.5。以下命令在课程总目录执行：

```powershell
python -m venv .venv
./.venv/Scripts/python.exe -m pip install -r requirements.txt
./.venv/Scripts/python.exe ./02_image_io/demo.py
./.venv/Scripts/python.exe ./02_image_io/exercise_solution.py
```

安装需要联网，示例运行不需要下载模型或素材。使用虚拟环境的Python完整路径，无须修改PowerShell执行策略或全局Python环境。此后把课程命令开头的 `python` 替换成 `./.venv/Scripts/python.exe` 即可；建议一直在课程总目录运行带周目录的命令。

依赖固定为NumPy 2.1.3和opencv-python 4.12.0.88，用于复现本课程环境，不表示它们是最新版本。OpenCV包的发布版本包含构建后缀，而 `cv2.__version__` 通常显示4.12.0，两者不矛盾。

课程不依赖contrib额外模块。在同一个环境里，opencv-python、opencv-contrib-python及它们的headless版本不要混装，它们提供同一个cv2模块。若已有复杂工作环境，使用上面的独立环境更容易排错。包选择与GUI差异见[官方说明](https://github.com/opencv/opencv-python)。

## 4. 编辑和运行不是一回事

用喜欢的编辑器打开 `.py` 查看和修改代码，用终端 `python 文件路径` 执行。终端显示 `>>>` 时表示进入了Python交互模式，此时不能直接输入PowerShell命令；先输入 `exit()` 返回终端。

Markdown文件是可阅读的讲义，不是Python程序，不要用Python运行 `.md`。

第一次按以下顺序：

1. 打开第2周的 `README.md`，确定本次任务。
2. 阅读 `讲义.md`，预测主程序的结果。
3. 运行 `demo.py`，打开该周 `outputs` 中的图片。
4. 修改一个参数，再运行，观察变化。
5. 自己做练习，再运行 `exercise_solution.py` 比较。

## 5. 输出和素材约定

所有默认图片和视频由代码生成，并固定随机种子；因此不必下载照片、视频、权重或数据集。默认只写本周outputs，不访问摄像头，也不弹出窗口。讲义中的图片已经生成，离线也能阅读。

`demo.py` 保存主结果，`exercise_solution.py` 用 `exercise_` 前缀保存练习结果。重新运行会覆盖对应同名文件，想保留自己的结果时请复制或改名。两份代码应放在同一个周文件夹，因为参考答案会导入主代码中的工具函数。

第8周可选运行 `python ./08_video/demo.py --camera 0 --show` 使用摄像头；按Q结束。未安装GUI组件或没有显示环境时，只运行默认无窗口示例。

第12周可选使用 `calibrate_real.py` 处理自己的棋盘照片；第15、16周可用 `--input` 换成自己的图片，方法见对应讲义。真实输入需要另外准备，课程未冒充已完成真实设备验证。

## 6. 只做必要的自检

```powershell
python run_all.py
```

此命令会顺序运行第2～16周的30个Python默认脚本、检查关键预期结果、更新验证结果JSON。它不测试真实相机，不会训练大型网络。每次学习不必运行全套；只有更换环境或修改公共约定后，整体自检才有必要。

出错时先看[术语与排错](术语与排错.md)，记录完整报错、运行命令、Python版本和最先异常的中间图，避免只写“运行不了”。
