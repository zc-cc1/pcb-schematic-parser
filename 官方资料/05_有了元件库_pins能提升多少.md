# 05 有了官方元件库，PinF1 能提升多少？

> 一句话：**现在提升不了（A/B 里 on/off 完全一样）；但库不是没用——它被上游的「位号」卡住了。**
> 把位号修好后，库能把 PinF1 的 box 口径从 **.076 抬到 .730**（TP 4 → 58）。
> 数字由 `_derive/pin_library_ceiling.py` 生成，原始输出 `D:/pcb_unet_v2/reports/pin_library_ceiling.txt`。

## 1. 为什么现在没提升

上一轮的 box 库 A/B：`off` 与 `on` 的加权总分都是 `.1738`，逐项也完全相同。
原因很简单——**能计分的 box 引脚一共只有 4 个**，库改的是编号和名称，翻不动这 4 个数。

## 2. 三段分解（都是实测）

### 段一：库本身给得准不准？—— 准

`open_GT` 13 例有真实型号，含 31 个 box 元件、**191 个 box 引脚**：

| 检查项 | 结果 |
|---|---|
| 编号在库中存在 | **168 / 191 = 88%** |
| 编号 **且** 名称与库中某一组完全一致 | **168 / 191 = 88%** |

差的 23 个是两个非芯片的框（`5V2A in/out`）和一个插座（`H1`），型号查不到。
以前担心的「名称别名要消歧」在这 13 例上没有真正发作——库给的多别名里恰好包含参考用的那个写法。

### 段二：PinF1 的分母有多大？

10GT 一共 **378 个引脚**，其中**只有 101 个属于 box/ic**（26.7%）。
其余 277 个是 R/C/L/GND/网络标号的引脚，**库对这些什么都给不了**，官方也明说它们不参与评分。
（若按「分母只算 box」的字面读法，分母就是 101；若按「非 box 也算但不要求编号名称」的读法，分母是 378。）

### 段三：那到底卡在哪？

拿现有预测（autoid 变体），对每个参考 box 元件做对照：

| 统计口径 | 数量 | 占 101 |
|---|---:|---:|
| 用**当前导出的键**能找到 ≤5 px 的对应点 | **4** | 4% ← 现在是这个数被计分 |
| 不按键、在**所有**导出元件里找位置最贴合的 | **80** | 79% |
| 再要求编号+名称也对 | **58** | 57% ← PinF1 的现实上限 |

**这 80 个位置正确的引脚，全都挂在 `DET_00xx` 这类自动编号下面**——box 元件的位号没读出来，
于是「元件 + 它的引脚 + 它所在的网络」整块计 0。

最典型的是 `0100`：库已经识别出 `DRV8824-Q1`（一致性 0.885），把 28 个引脚全命名了，
位置也 28/28 落在 5 px 内——但元件键是 `DET_0033` 而不是 `U1`，所以一分没有。

## 3. 所以库的作用是什么

| 阶段 | 库的作用 | 结果 |
|---|---|---|
| 现在 | 可有可无（只有 4 个引脚能计分） | 分数不动 |
| **位号修好后** | **把编号、名称一次锁对（88%）** | TP 4 → 58，PinF1（box 口径）**.076 → .730** |
| 网络超图（35%） | 作用更大：`hyperGraph` 写的是 `元件.引脚编号`，编号对了 pin set 才可能对上 | 见 `04_实测_导出与评分口径.md` |

一个重要的反面结论：**别把力气花在让库更准上**。库这一侧已经 88% 到顶，
剩下 12% 是查不到型号的非芯片框；而「位号」这一侧一动就是 20 倍（4 → 80）。

## 4. 还有哪些不是库能解决的

1. **剩下 21 个位置不对的 box 引脚**（101 − 80）：检测/U-Net 的 tip 定位问题。
2. **分母 101 vs 378 的读法差别**：若官方把非 box 引脚也计入分母，
   box 全部做对也只有 `.73 × 101 / 378` 量级的贡献，非 box 引脚必须靠「位置」而不是「身份」去拿分。
3. **box 元件本身的检出**：`0042` 的 U1 有 20 个引脚，预测里根本找不到位置对应的元件块——漏检，不是身份问题。

## 5. 行动顺序（按收益/成本）

1. **修 box 元件的位号读取**（大 IC 旁边的 `U1/U2` 丝印）：一步换 4 → 80 的位置可用率。
2. **位号一通，接库**：编号+名称直接回填（现成的 `box_model_index.json` + 已有的
   `component_pin_library` 一致性闸门），TP 到 58。
3. 再谈剩下的 21 个位置偏差（tip 定位）——这是纯几何问题，与库无关。
