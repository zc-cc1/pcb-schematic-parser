# YOLO11s 相同末阶段配置训练与对比
训练与评测于北京时间2026-10-12 21:08前完成。完整训练120轮，未触发提前停止，框架记录训练耗时4.055小时；mAP50-95最佳checkpoint来自第119轮（mAP50=0.75640、mAP50-95=0.57476）。v8n原部署阈值计数完全复现：TP2182/FP298/FN280，F1=0.883043。

裁决：本次YOLO11s未超越当前v8n。按相同方法重调阈值，best F1=0.880148，last F1=0.881104，均低于v8n的0.885616；即便用last，仍低0.451个百分点。保持现有部署权重，保留新best/last；已停止完成跟进，避免重复报告。

主要差异：best在电容上F1从v8n的0.8889降至0.8041（少40个TP、多44个FP），但IC从0.9223升至0.9679，开关从0.7290升至0.8713。融合推理中位耗时v8n约110.3ms/页、YOLO11s best约135.0ms/页；这是本机59页、单次预热后的观测，非普遍硬件结论。

best-v8n同法重调F1差的逐页配对bootstrap95%区间为[-0.03308,+0.01734]，跨零，且未修正调阈值选择偏差。当前验证结果支持保留v8n，不证明架构差距已确定。

YOLO11s 从 COCO 权重重新训练；现有 v8n 有任务热启动历史。因此参数对齐，但初始化历史不同。以下是本地类别+bbox F1，不是官方 ComponentF1。

| 模型 | 全局 conf 0.2 F1 | 相同方法逐类重调 F1 | P / R（重调） |
|---|---:|---:|---|
| v8n_adopted | 0.858801 | 0.885616 | 0.8798 / 0.8916 |
| y11s_best | 0.849219 | 0.880148 | 0.8926 / 0.8680 |

YOLO11s best 与 v8n 的同法重调 F1 差：-0.005468（-0.547 个百分点）。

重调在同一验证集上选择并计分，存在选择偏差；paired bootstrap 区间也没有修正此偏差。部署模型未自动替换。
