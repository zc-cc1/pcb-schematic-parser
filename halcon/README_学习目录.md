# HALCON 12 周学习目录

适配环境：HALCON 20.11 Steady。总计划见 [HALCON学习计划.md](HALCON学习计划.md)。

本目录已按“准备阶段 + 12 个学习周”拆分。每周目录尽量保持相同结构：

- `README_第X周.md`：目标、每日安排、实践任务、验收标准。
- `HALCON算子卡片.md`：本周重点算子的用途、参数和常见问题。
- `练习代码/`：练习说明与周项目起始模板。
- `学习记录/第X周打卡表.md`：每日打卡、参数实验、问题和复盘。

## 每周固定节奏

1. 第 1 天：理解对象、流程和使用场景。
2. 第 2～3 天：运行最小示例，记录输入、输出和关键参数。
3. 第 4 天：制造噪声、亮度、旋转、遮挡等干扰并对比。
4. 第 5 天：在多张图片上批量测试，记录耗时和失败样本。
5. 第 6 天：完成周项目并按验收标准自测。
6. 第 7 天：只复盘、补漏和整理，不增加新知识。

## 文件使用规则

- 自己采集的数据按 `开发集/调参集/测试集` 分开，避免用同一批图片完成调参和最终评估。
- 原图只读保存；中间结果、日志和失败样本放到各周独立的 `output` 目录，不覆盖原图。
- 周项目模板只给出流程骨架。先独立补齐 TODO，再参考官方示例。
- 每个关键参数至少做 3 组对比，并在打卡表中记录“效果、耗时、失败条件”。
