# 第 7 周练习任务

1. `01_coordinate_systems.hdev`：行列、X/Y、角度和单位练习。
2. `02_calibration_image_check.hdev`：标定图检测与覆盖检查。
3. `03_camera_calibration.hdev`：完整标定数据流程。
4. `04_image_to_world_plane.hdev`：点到世界平面坐标转换。
5. `05_world_distance_validation.hdev`：多位置标准件误差统计。
6. `06_week_project_planar_measurement.hdev`：平面测量与验证报告。

标定 API 的参数较多，先从与你的相机模型一致的官方示例复制最小流程，再逐行解释和替换；不要混用不同相机模型的参数元组。
