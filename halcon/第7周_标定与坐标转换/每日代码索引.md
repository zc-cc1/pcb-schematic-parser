# 第7周每日代码索引

建议按编号依次运行。示例使用 HALCON 自带的 `calib/calib-3d-coord-*` 图像和 `caltab_big.descr`，无需另外下载素材。

| 天数 | 文件 | 本日重点 |
|---|---|---|
| 第1天 | `练习代码/01_coordinate_systems.hdev` | Row/Column、X/Y、像素点到世界平面 |
| 第2天 | `练习代码/02_calibration_image_check.hdev` | 批量检测标定板并检查覆盖 |
| 第3天 | `练习代码/03_camera_calibration.hdev` | 完整标定并读取内参与误差 |
| 第4天 | `练习代码/04_image_to_world_plane.hdev` | 图像校正到世界平面 |
| 第5天 | `练习代码/05_world_distance_validation.hdev` | 世界坐标距离与多点验证 |
| 第6天 | `练习代码/06_week_project_planar_measurement.hdev` | 标定、校正、测量周项目 |

运行说明：第2～6天执行时间略长。若 `find_calib_object` 失败，先检查 HALCON 示例图像路径是否已安装。
