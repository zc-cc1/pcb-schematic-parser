# 第 6 周练习任务

1. `01_measure_rectangle_direction.hdev`：测量矩形和方向可视化。
2. `02_measure_pos_polarity.hdev`：边缘极性和选择方式。
3. `03_measure_pairs_width.hdev`：边缘对、宽度和间距。
4. `04_geometry_distance.hdev`：点点距离、点线距离、交点和夹角。
5. `05_repeatability_30_runs.hdev`：30 次重复性统计。
6. `06_week_project_dimension_inspection.hdev`：公差判断与结果输出。

每个测量点都要叠加显示；如果边缘数量异常，先报告错误，禁止直接取元组第一个值。
