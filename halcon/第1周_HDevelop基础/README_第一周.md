# HALCON 第 1 周：HDevelop 与基础语法

适配环境：HALCON 20.11 Steady

本周总目标：能够不复制完整示例，独立写出“读取图片—取得信息—显示结果—批量浏览—处理异常”的 HDevelop 程序。

## 本周安排

| 天数 | 主题 | 对应程序 | 当天成果 |
|---|---|---|---|
| 第 1 天 | 界面、运行、单步、断点 | `练习代码/01_hello_hdevelop.hdev` | 读图并显示尺寸 |
| 第 2 天 | 图标变量与控制变量 | `练习代码/02_variables_and_objects.hdev` | 区分 Image、Region、数值、字符串、元组 |
| 第 3 天 | 元组、循环和条件判断 | `练习代码/03_tuple_loop_condition.hdev` | 循环显示 3 张图片 |
| 第 4 天 | 图形窗口与结果叠加 | `练习代码/04_visualization.hdev` | 在图像上叠加 ROI 和文字 |
| 第 5 天 | 异常处理 | `练习代码/05_try_catch.hdev` | 捕获读图失败，不让程序直接中断 |
| 第 6 天 | 周项目：图片浏览器 | `练习代码/06_week_project_image_browser.hdev` | 批量浏览目录中的图片 |

建议每天学习 90～120 分钟。第 7 天只复盘、补漏，不增加新内容。

## 第 1 天：现在从这里开始

### 1. 先认识 HDevelop 的五个区域

打开 HDevelop 后，重点找到：

1. 程序窗口：编写和执行算子。
2. 图形窗口：显示 Image、Region、XLD 和文字结果。
3. 图标变量窗口：查看图像、区域、轮廓等视觉对象。
4.控制变量窗口：查看数字、字符串、元组和句柄。
5. 算子窗口与帮助：搜索算子、查看四组参数及示例。

HALCON 算子在帮助文档中通常按下面四组参数理解：

```text
算子 (图标输入 : 图标输出 : 控制输入 : 控制输出)
```

例如 `get_image_size`：输入是图像，输出的宽和高是控制变量。

### 2. 运行第一个程序

打开 `练习代码/01_hello_hdevelop.hdev`，完成以下操作：

1. 完整运行一次，确认看到 `fabrik` 示例图和尺寸文字。
2. 清空程序执行状态，改用单步执行。
3. 在 `get_image_size` 行设置断点，再次运行。
4. 在图标变量窗口双击 `Image`。
5. 在控制变量窗口查看 `Width`、`Height` 和 `ImageName`。
6. 把 `ImageName := 'fabrik'` 改成 `ImageName := 'clip'` 再运行。

### 3. 第 1 天必须理解的概念

- `Image` 是图标变量，保存的不是普通数字，而是 HALCON 图像对象。
- `Width`、`Height` 是控制变量，保存数值。
- `ImageName` 是控制变量，保存字符串。
- `read_image` 创建图像对象；`get_image_size`读取图像信息。
- `dev_display` 负责在当前图形窗口显示对象。
- `dev_set_part` 设置图像坐标与窗口之间的显示映射。

### 4. 第 1 天练习

不要查看其他程序，独立完成：

1. 把显示窗口改为 `800 × 600`。
2. 把文字颜色从白色改为黄色。
3. 增加一行文字：`我的第一个 HALCON 程序`。
4. 故意把图片名改成一个不存在的名字，观察错误位置和错误信息，然后恢复。
5. 在学习记录中写出 `read_image` 和 `get_image_size` 的输入、输出。

### 5. 第 1 天验收

在不看源程序的情况下回答：

- 哪些变量会出现在图标变量窗口？
- 哪些变量会出现在控制变量窗口？
- 为什么必须先 `read_image`，才能 `get_image_size`？
- 图形窗口大小和原始图像分辨率是同一件事吗？

四题中能清楚回答三题，即可进入第 2 天。

## 第 2 天：变量与对象

### 学习重点

- 图标变量：Image、Region、XLD。
- 控制变量：整数、实数、字符串、元组、句柄。
- 一个 HALCON 图标变量可以包含一个或多个对象。
- `reduce_domain` 只缩小图像的有效定义域，不等于修改图像的像素尺寸。

### 操作任务

1. 运行 `02_variables_and_objects.hdev`。
2. 分别双击 `Image`、`ROI`、`ImageReduced`，观察显示差别。
3. 查看 `ImageNames`、`NumberOfImages`、`Width`、`Height`。
4. 修改 ROI 坐标，观察有效区域变化。

### 验收

能用自己的话说明 Image、Region、控制元组三者的区别。

## 第 3 天：元组、循环与条件

### 学习重点

- 使用 `[]` 创建元组，使用 `Tuple[Index]` 取元素。
- 使用 `|Tuple|` 获取元组长度。
- 掌握 `for`、`if/else/endif`。
- 变量名应表达含义，例如 `ImageIndex`，不要只使用 `a`、`b`。

### 操作任务

1. 运行 `03_tuple_loop_condition.hdev`。
2. 每次遇到 `stop ()` 后查看变量，再继续执行。
3. 增加图片 `rings_and_nuts`。
4. 增加一个计数变量，记录横向图片的数量。

### 验收

独立写出一个循环，依次打印元组中的 5 个数字。

## 第 4 天：可视化

### 学习重点

- 图像通常先显示，区域、轮廓和文字随后叠加。
- `dev_set_draw ('margin')` 只画区域边界。
- `dev_set_draw ('fill')` 填充区域。
- 颜色、线宽和文字只是显示效果，不会改变图像数据。

### 操作任务

1. 运行 `04_visualization.hdev`。
2. 交换矩形与圆的颜色。
3. 将线宽分别改为 1、3、8，观察差异。
4. 将 `margin` 改为 `fill`，回答图像数据是否发生变化。

### 验收

能够在一张图片上显示两个不同颜色的 ROI，并添加说明文字。

## 第 5 天：异常处理

### 学习重点

- 真实项目不能假设每张图片都一定能读取。
- `try/catch/endtry` 用于捕获运行错误。
- 捕获异常后应记录错误，并决定继续、重试或结束。
- 不应使用异常处理掩盖算法本身的错误。

### 操作任务

1. 运行 `05_try_catch.hdev`。
2. 确认中间的无效图片会报错，但下一张有效图片仍能处理。
3. 查看异常中的 `error_code` 和 `error_msg`。
4. 再增加一个无效文件名，统计成功和失败数量。

### 验收

程序能批量处理图片；某一张失败时，其余图片仍能继续。

## 第 6 天：周项目——图片浏览器

### 基础要求

运行 `06_week_project_image_browser.hdev`，然后独立扩展：

1. 显示当前序号和总数。
2. 显示文件名、图像宽度和高度。
3. 区分横向、竖向和方形图片。
4. 统计成功与失败数量。
5. 对读图异常进行捕获。

### 加分要求

- 把浏览目录改成自己的图片目录。
- 记录每张图片的处理时间。
- 把显示部分整理成一个本地过程。

### 周验收标准

- 能在 30 分钟内从空白程序写出简化版图片浏览器。
- 能解释至少 8 个本周算子的输入、输出和作用。
- 能熟练使用单步、断点和变量窗口定位问题。
- 无效图片不会导致整个批处理直接退出。

1. 重做第 1 天程序，不打开原文件。
2. 完成 `学习记录/第1周打卡表.md`。

## 本周不要提前深挖的内容

阈值分割、滤波、形态学、模板匹配暂时只需知道名称。本周重点是熟悉 HDevelop、变量、控制结构、显示、文件和调试；基础扎实后，后续算法学习会明显更快。
