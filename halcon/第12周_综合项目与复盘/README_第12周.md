# HALCON 第 12 周：综合项目与答辩式复盘

本周总目标：交付一个可重复运行的“零件定位与质量检测系统”，用独立测试集评估正确率、漏检率、误检率和耗时，并能解释成功与失败原因。

## 推荐项目流程

```text
批量读图/采集
→ 图像质量检查与预处理
→ 形状匹配定位
→ ROI 跟随变换
→ 尺寸/缺陷/有无/OCR 中至少两项检测
→ 规则融合与 OK/NG
→ 可视化、日志、失败图片保存
→ 独立测试集统计
```

## 本周安排

| 天数 | 主题 | 主要成果 |
|---|---|---|
| 第 1 天 | 需求、指标、数据冻结 | 项目规格与数据清单 |
| 第 2 天 | 定位、ROI、预处理主链路 | 稳定定位结果 |
| 第 3 天 | 两项检测功能 | 尺寸/缺陷/有无/OCR |
| 第 4 天 | 异常、日志、资源与配置 | 可连续批量运行 |
| 第 5 天 | 独立测试集评估 | 完整指标与失败归档 |
| 第 6 天 | 报告、流程图、演示与答辩 | 最终交付包 |
| 第 7 天 | 总复盘 | 后续提升路线 |

## 第 1 天：冻结规格和数据

1. 写清输入、输出、节拍、公差、缺陷最小尺寸和不可判定策略。
2. 将样本分为开发集、调参集、测试集；测试集在最终评估前不反复查看。
3. 冻结模型版本、配置版本和测试集清单。
4. 建立真实标签，确认正常/异常类别和数量。

## 第 2～3 天：实现主流程

- 检查图像是否为空、过暗、过亮或尺寸异常。
- 用形状模型定位，明确无目标、低分和多目标策略。
- 一致变换检测 ROI。
- 从尺寸、缺陷、有无和字符中至少选两项，输出可量化结果。
- 将各子结果融合为最终状态，并保留原始子结果。

## 第 4 天：工程完整性

- 参数集中配置，模型和配置含版本信息。
- 日志包含图片 ID、状态、结果、分数、耗时和失败阶段。
- 保存失败图片与必要中间结果，不覆盖输入。
- 连续运行全部图片，无需手工点选 ROI 或修改变量。
- 正常与异常退出都释放所有模型和句柄。

## 第 5 天：独立测试

至少统计：正常/异常样本数、正检、误检、漏检、定位成功率、测量误差或识别成功率、平均耗时、最大耗时。把定位失败与检测错误分开统计。

## 第 6 天：交付与答辩

最终交付物：

1. HDevelop 源程序及 Procedure。
2. 模型、配置和版本说明。
3. 数据集结构与测试图片清单，不重复打包无关大文件。
4. 算法流程图和参数说明表。
5. 测试报告与失败案例分析。
6. 可重复运行的入口和操作说明。

答辩时能够回答：为什么选此算法、参数如何确定、在哪些条件下失败、如何证明结果稳定、下一步优先改光学/机构/算法中的哪一项。

## 最终验收标准

- 测试集不全部来自调参时使用的样本。
- 程序可一次连续运行全部测试图，无人工干预。
- 检测结果可重复，异常输入有明确错误信息。
- 报告包含定量指标，不只展示成功截图。
- 至少列出 5 个失败样本、根因和改进方案。
