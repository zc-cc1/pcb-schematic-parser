# 第12周每日代码索引

综合项目采用“可运行的合成零件检测线”作为基线：形状匹配定位、位姿对齐、面积检测、缺陷差分、状态输出和测试统计。之后可逐步替换成真实数据。

| 天数 | 文件 | 本日重点 |
|---|---|---|
| 第1天 | `练习代码/01_requirements_and_dataset.hdev` | 把需求和数据划分写成变量 |
| 第2天 | `练习代码/02_localization_pipeline.hdev` | 建模、搜索、位姿输出 |
| 第3天 | `练习代码/03_two_quality_checks.hdev` | 面积完整性和表面缺陷两项检测 |
| 第4天 | `练习代码/04_result_logging.hdev` | CSV 日志及失败信息 |
| 第5天 | `练习代码/05_test_metrics.hdev` | TP/TN/FP/FN、准确率和召回率 |
| 第6天 | `练习代码/main_project_template.hdev` | 完整综合项目主程序 |

建议复制 `main_project_template.hdev` 为自己的项目主程序，再替换成相机图像、实际 ROI、规格阈值和保存路径。
