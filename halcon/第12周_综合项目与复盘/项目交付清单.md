# 第 12 周项目交付清单

## 1. 需求与版本

- [ ] 输入、输出、节拍、精度、公差和缺陷规格已写清。
- [ ] 相机、镜头、光源、工作距离和 HALCON 版本已记录。
- [ ] 模型、配置、程序和测试集都有版本或日期标识。
- [ ] 开发集、调参集、测试集已分开。

## 2. 程序

- [ ] 有单一批量运行入口。
- [ ] 定位、ROI 变换和至少两项检测均已完成。
- [ ] 参数集中配置，无深层硬编码关键阈值。
- [ ] 无目标、低分、多目标、边缘不足、异常输入有明确状态。
- [ ] 所有句柄正常释放。
- [ ] 失败图片和日志自动保存。

## 3. 测试

- [ ] 测试集未用于最终调参。
- [ ] 正常和异常样本数量已统计。
- [ ] 正检、误检、漏检、定位失败已分开统计。
- [ ] 测量误差/识别率/重复性已统计。
- [ ] 平均、最大耗时已统计。
- [ ] 至少 5 个失败样本完成根因分析。

## 4. 文档与演示

- [ ] 算法流程图。
- [ ] 参数说明表。
- [ ] 数据集与目录说明。
- [ ] 测试报告。
- [ ] 运行说明。
- [ ] 5～10 分钟演示步骤。
- [ ] 后续改进清单。
