# 第8周每日代码索引

本周全部示例使用 HALCON 自带图像 `rings_and_nuts`。每个创建模型的程序末尾都调用 `clear_shape_model`。

| 天数 | 文件 | 本日重点 |
|---|---|---|
| 第1天 | `练习代码/01_create_shape_model.hdev` | 模板 ROI、方向特征、建模与回查 |
| 第2天 | `练习代码/02_find_shape_model.hdev` | 安全处理 0、1、多个结果 |
| 第3天 | `练习代码/03_follow_roi_with_pose.hdev` | 模型原点、轮廓及检测 ROI 随位姿移动 |
| 第4天 | `练习代码/04_parameter_scan.hdev` | 角度、分数、层级、重叠率、贪婪度扫描 |
| 第5天 | `练习代码/05_matching_stress_test.hdev` | 六类 60 张带真值压力测试 |
| 第6天 | `练习代码/06_week_project_part_localization.hdev` | 定位、ROI 跟随与五类异常状态 |
| 第7天 | 本周 6 个程序 | 复跑验收、35 道标准答案与生产差距复盘 |
