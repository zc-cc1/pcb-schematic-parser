## 1. 面积与中心：`area_center`

```halcon
area_center (SortedRegions, Areas, Rows, Columns)
```

如果输入包含 7 个区域对象，三个输出都是长度为 7 的元组：

```text
Areas[0]、Rows[0]、Columns[0] → 第 1 个目标
Areas[1]、Rows[1]、Columns[1] → 第 2 个目标
```

HALCON 使用 `(Row, Column)` 表示图像坐标：

```text
Row    → 纵向坐标，向下增大
Column → 横向坐标，向右增大
```

因此不要把它直接写成常见数学坐标 `(x,y)`；对应关系通常是 `x=Column`、`y=Row`。

## 2. 轴对齐外接矩形：`smallest_rectangle1`

```halcon
smallest_rectangle1 (Regions, Row1, Column1, Row2, Column2)
```

输出矩形始终与图像行列轴平行：

```text
(Row1, Column1) → 左上角
(Row2, Column2) → 右下角
```

它适合快速获得范围、宽高和 ROI，但不会跟随旋转目标的方向。旋转目标的紧致包围通常要使用 `smallest_rectangle2`，将在后续几何章节深入学习。

## 3. 最小外接圆：`smallest_circle`

```halcon
smallest_circle (Regions, CircleRows, CircleColumns, Radii)
```

它返回能够完全包住区域的最小圆，而不是区域内部孔洞的圆，也不是圆度本身。因此：

- 可以估计圆形目标的位置和外部尺寸。
- 非圆形目标也能得到外接圆。
- 不能仅凭外接圆存在就判断目标是圆形。

## 4. 稳定排序：`sort_region`

```halcon
sort_region (Regions, SortedRegions, 'character', 'true', 'row')
```

本例参数表示：

- `'character'`：把区域看成多行字符进行排序。
- `'true'`：使用正向顺序。
- `'row'`：同行从左到右，然后从上到下。

得到的顺序为：

```text
第一行：左 → 右
第二行：左 → 右
```

`sort_region` 只改变区域对象在对象数组中的顺序，不移动目标，也不改变区域形状。

排序的稳定性取决于目标布局。如果两行目标严重倾斜或上下范围大量重叠，`'character'` 的分行结果可能改变，需要先做姿态校正、分行或使用更明确的业务规则。

## 5. 区域合并：`union1`

```halcon
union1 (SortedRegions, RegionUnion)
```

它把所有输入区域对象合成一个 Region 对象。几何像素仍然存在，但原来的对象边界和顺序不再保留：

```text
合并前：7 个区域对象 → 7 组面积、中心和编号
合并后：1 个区域对象 → 1 个总面积和整体重心
```

`union1` 适合构造整体 ROI、整体掩膜或进行集合运算；如果后续还需要逐目标计数、编号或测量，应保留合并前的区域数组。


```halcon

```
