# 第三周第 3 天：连通域与区域筛选

## 今日目标

前两天解决了“哪些像素可能属于目标”。今天继续解决两个问题：

1. 怎样把分散的候选像素拆成一个个候选目标？
2. 怎样利用目标的物理特征排除干扰并进行分类？

核心流程是：

```text
阈值分割 → connection → 特征统计 → select_shape → count_obj
```

## 1. `connection`：从候选像素到候选目标

阈值分割输出的是一个 Region 对象。即使里面有多个互不接触的区域，直接执行 `count_obj` 通常仍只会得到一个对象。

```halcon
threshold (Image, RegionThreshold, 0, 130)
connection (RegionThreshold, ConnectedRegions)
count_obj (ConnectedRegions, ConnectedCount)
```

`connection` 按像素连通关系，把联合区域拆成区域对象数组。拆分后才能分别计算每个候选目标的面积、位置和形状。

需要注意：

- 噪点也会被拆成独立连通域。
- 两个目标如果粘连，仍可能成为同一个连通域。
- `connection` 只拆分，不判断哪个区域是真目标。

## 2. 读取每个候选区域的特征

```halcon
area_center (ConnectedRegions, Areas, Rows, Columns)
region_features (ConnectedRegions, 'width', Widths)
region_features (ConnectedRegions, 'height', Heights)
region_features (ConnectedRegions, 'circularity', Circularities)
```

当输入包含多个区域对象时，输出是元组：

```text
Areas[0]、Widths[0]、Circularities[0] → 第 1 个区域
Areas[1]、Widths[1]、Circularities[1] → 第 2 个区域
```

常用特征的物理意义：

| 特征 | 含义 | 常用于排除 |
|---|---|---|
| `area` | 区域像素数量 | 小噪点、异常大区域 |
| `width` | 轴对齐外接矩形宽度 | 过宽或过窄的干扰 |
| `height` | 轴对齐外接矩形高度 | 细线、矮小干扰 |
| `circularity` | 区域接近圆形的程度，通常为 `0～1` | 不够圆的目标 |
| `rectangularity` | 区域填充外接矩形的程度 | 不够矩形的目标 |

圆度接近 `1` 表示更接近圆形，但带孔、锯齿边缘和分割缺口都会降低圆度。

## 3. `select_shape`：按物理特征筛选

```halcon
select_shape (ConnectedRegions, AreaSelected, \
              'area', 'and', 1000, 7000)
```

只保留面积在 `1000～7000` 之间的区域。

多个特征也可以一起使用：

```halcon
select_shape (AreaSelected, SizeSelected, \
              ['width','height'], 'and', [50,50], [130,130])
```

这里要求：

```text
50 <= width  <= 130
并且
50 <= height <= 130
```

`'and'` 表示所有条件都要满足；`'or'` 表示至少满足一个条件。

## 4. 今天示例中的筛选逻辑

程序使用 `rings_and_nuts`：

```text
阈值 + connection：8 个候选区域
面积筛选：仍为 8 个
宽高筛选：去掉顶部细长边界，保留 7 个零件
圆度筛选：从 7 个零件中选出 4 个圆度较高的螺母
剩余区域：3 个带齿零件
```

面积筛选故意没有去掉顶部边界。这能说明：面积相近不代表形状相同，必须根据干扰的实际特征选择条件。

## 必做实验

### 实验一：面积下限

依次修改：

```text
AreaMin := 500
AreaMin := 1800
AreaMin := 3000
```

观察每个条件分别排除了什么，以及是否误删了真实的小零件。

### 实验二：只用宽度或只用高度

将宽高联合筛选暂时拆成单特征筛选，比较哪个特征真正排除了顶部细线：

```halcon
select_shape (AreaSelected, WidthSelected, 'width', 'and', 50, 130)
select_shape (AreaSelected, HeightSelected, 'height', 'and', 50, 130)
```

### 实验三：圆度下限

依次修改：

```text
CircularityMin := 0.45
CircularityMin := 0.55
CircularityMin := 0.65
```

观察条件过松时是否混入齿形零件，条件过紧时是否漏掉真实螺母。
