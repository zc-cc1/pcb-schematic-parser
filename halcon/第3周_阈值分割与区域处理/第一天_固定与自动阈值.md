# 第三周第 1 天：固定阈值与自动阈值

## 今日目标

今天只解决一个核心问题：怎样把灰度图中的目标像素变成可处理的 `Region`。

完成练习后，你应当能够：

1. 解释 `threshold` 的最小、最大灰度参数。
2. 根据“目标比背景暗/亮”选择分割极性。
3. 使用 `binary_threshold` 自动计算一个分割阈值。
4. 说清 `auto_threshold` 与二值阈值的区别。
5. 解释固定阈值在整体亮度变化时为什么会失败。

## 先建立直觉

对 byte 灰度图，每个像素的灰度通常位于 `0～255`：

```text
0（黑） ---------------- 128（灰） ---------------- 255（白）
```

阈值分割就是逐像素判断：灰度是否位于指定范围内。满足条件的像素进入输出区域，不满足的像素留在区域之外。

```text
Image（图像） -- threshold 0,100 --> Region（区域）
```

注意：输出是区域，不是把原图改成只有黑白两种灰度的新图像。

## 三种方法

### 1. 固定阈值 `threshold`

```text
threshold (Image, RegionFixed, 0, 100)
```

含义：保留灰度在 `0～100` 之间的像素。当前示例是“黑色零件、白色背景”，因此选择暗像素。

优点是简单、快速、结果容易解释；风险是曝光或光源变化后，原来合理的 `100` 可能不再合理。

### 2. 自动二值阈值 `binary_threshold`

```text
binary_threshold (Image, RegionBinary, 'max_separability', 'dark', UsedThreshold)
```

- `max_separability`：寻找能较好分开两类灰度的阈值。
- `dark`：输出较暗的一类像素。
- `UsedThreshold`：算子实际找到的阈值，必须观察并记录。

它仍然是二分类，只是阈值不再由人直接写死。

### 3. 多阈值 `auto_threshold`

```text
auto_threshold (Image, RegionsAuto, 2.0)
```

它会根据平滑后的直方图谷底把灰度分成多个类别，因此输出可能包含多个 Region 对象，不保证只有“目标”和“背景”两类。`Sigma` 越大，直方图被平滑得越强，通常得到的类别越少。

打开 `练习代码/01_threshold_methods.hdev`，完整运行一次。每遇到 `stop ()`，先观察图形窗口，再继续。

## 必做实验

### 实验一：修改固定阈值上限

依次尝试：

```text
FixedMax := 60
FixedMax := 100
FixedMax := 160
```

记录哪个值能保留零件，同时不过多选择背景和阴影。

### 实验二：故意选错极性

把：

```text
binary_threshold (Image, RegionBinary, 'max_separability', 'dark', UsedThreshold)
```

暂时改为：

```text
binary_threshold (Image, RegionBinary, 'max_separability', 'light', UsedThreshold)
```

观察输出为何变成背景。实验后改回 `dark`。

### 实验三：修改亮度

把：

```text
scale_image (Image, DarkImage, 0.35, 0)
```

分别改成系数 `0.5`、`0.7`、`0.9`。比较固定阈值与自动二值阈值的区域面积变化。
