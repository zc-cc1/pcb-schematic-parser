# 第 3 周算子卡片

| 算子 | 作用 | 关键参数/输出 | 常见问题 |
|---|---|---|---|
| `threshold` | 固定灰度范围分割 | 最小、最大灰度 | 光照变化导致漂移 |
| `binary_threshold` | 自动二值化 | 方法、目标极性 | 直方图不明显时不稳定 |
| `auto_threshold` | 多阈值分割 | 平滑参数 | 可能产生多个区域类 |
| `dyn_threshold` | 图像与参考图比较 | 偏移量、`light/dark` | 参考图尺度选择错误 |
| `var_threshold` | 局部统计阈值 | 掩膜、标准差因子 | 参数多，必须批量验证 |
| `connection` | 拆分连通区域 | 输出区域对象数组 | 粘连目标仍无法分开 |
| `select_shape` | 按特征筛选 | 特征、逻辑、上下限 | 条件过紧造成漏检 |
| `select_shape_std` | 标准形状筛选 | 模式、百分比 | 适用范围有限 |
| `union1` | 合并区域对象 | 单一区域输出 | 合并后对象级信息丢失 |
| `sort_region` | 区域排序 | 行列方向、顺序 | 目标倾斜时顺序可能变化 |
| `area_center` | 面积与中心 | Area、Row、Column | 多区域输出是元组 |
| `smallest_rectangle1` | 轴对齐外接矩形 | 两组行列坐标 | 旋转目标宽高不准确 |
| `smallest_circle` | 最小外接圆 | 圆心、半径 | 非圆目标不能用来判断圆度 |
