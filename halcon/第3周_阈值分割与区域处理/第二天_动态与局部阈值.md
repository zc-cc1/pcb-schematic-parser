## 为什么全局阈值不够

固定阈值对整幅图只使用一个分界值：

```text
像素灰度 < 100 → 目标
```

但背景可能左边灰度为 `90`，右边灰度为 `180`。如果目标都只比各自背景暗 `20`：

```text
左侧：背景 90，目标 70
右侧：背景 180，目标 160
```

不存在一个固定阈值能同时选中 `70` 和 `160`，又排除背景 `90`。局部阈值不问“像素是否低于一个全局数值”，而问：

```text
这个像素是否明显低于它附近的背景？
```

## `dyn_threshold`：原图与参考图比较

典型流程：

```text
mean_image (Image, MeanImage, MaskWidth, MaskHeight)
dyn_threshold (Image, MeanImage, RegionDyn, Offset, 'dark')
```

`MeanImage` 是原图的平滑版本，可以近似表示各位置的局部背景。

对于 `dark`，像素满足下面的条件才会被选中：

```text
原图灰度 <= 参考图灰度 - Offset
```

例如某位置的局部背景是 `150`，`Offset = 10`，那么灰度不高于 `140` 的像素才会被选中。

### 两个关键参数

**掩膜大小**决定“周围”有多大。参考图必须能抹平目标并保留缓慢变化的背景。经验起点是掩膜边长约为目标直径的两倍，并使用奇数。

- 太小：目标也保留在参考图中，原图与参考图差别很小，可能漏检。
- 太大：可能把跨度较大的背景变化也当成目标，且相邻目标可能互相影响。

**`Offset`** 是目标相对局部背景至少需要达到的灰度差。

- 越小：越敏感，弱目标更多，但噪声和纹理也更多。
- 越大：结果更干净，但低对比目标可能消失。
- 不建议设为 `0`，否则微小噪声也容易被选中。

## `var_threshold`：局部均值与波动共同决定门槛

```text
var_threshold (Image, RegionVar, MaskWidth, MaskHeight, \
               StdDevScale, AbsThreshold, 'dark')
```

它直接在滑动窗口内计算局部均值 `m(x,y)` 和局部标准差 `d(x,y)`。当 `StdDevScale >= 0` 时，局部门槛为：

```text
v(x,y) = max(StdDevScale × d(x,y), AbsThreshold)
```

选择 `dark` 时：

```text
像素灰度 <= 局部均值 - v(x,y)
```

因此，噪声或纹理越强的区域，所需灰度差可以自动变大；`AbsThreshold` 则防止均匀区域因极小波动而产生大量误检。

## 两个算子的关系

| 方法 | 局部参照 | 主要参数 | 特点 |
|---|---|---|---|
| `dyn_threshold` | 由你先生成参考图 | 平滑掩膜、`Offset` | 流程直观，容易观察每一步 |
| `var_threshold` | 内部计算局部均值和标准差 | 掩膜、`StdDevScale`、`AbsThreshold` | 能根据局部噪声调整门槛 |

它们都不是万能的。目标尺寸、背景纹理和噪声改变时，都需要批量验证参数。

打开 `练习代码/02_dynamic_threshold.hdev` 并完整运行。每遇到 `stop ()`，观察当前图像和控制变量：

1. 原图：寻找跨越不同亮度区块的暗点。
2. 固定阈值：观察不同区块是否出现漏检或大面积误选。
3. `MeanImage`：暗点应被明显平滑，缓慢变化的背景仍被保留。
4. `dyn_threshold`：查看暗点能否在不同背景上同时被选出。
5. `var_threshold`：比较它与动态阈值的结果差异。

重点变量：

```text

DynOffset
VarMask
StdDevScale
AbsThreshold
GlobalArea / GlobalCount
DynArea / DynCount
VarArea / VarCount
```

注意：`DynCount` 和 `VarCount` 是 `connection` 后的候选连通域数，里面可能含噪点，不等于正确目标数。第 3 天才会正式学习筛选。
