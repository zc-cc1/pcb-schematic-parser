# HALCON 第 3 周：阈值分割与区域处理

本周总目标：从图像稳定获得目标区域，完成连通域分析、特征筛选、排序和计数，并理解固定阈值为什么会在光照变化时失败。

## 本周安排

| 天数 | 主题 | 主要成果 |
|---|---|---|
| 第 1 天 | 固定与自动阈值 | 建立基础分割流程 |
| 第 2 天 | 动态与局部阈值 | 处理亮度变化场景 |
| 第 3 天 | 连通域与区域筛选 | 去除杂点并保留目标 |
| 第 4 天 | 几何特征、合并与排序 | 输出目标位置与顺序 |
| 第 5 天 | 亮度压力测试 | 比较固定与动态阈值 |
| 第 6 天 | 周项目：零件计数 | 输出数量、特征和可视化 |
| 第 7 天 | 复盘 | 解释每个筛选条件的作用 |

## 核心流程

```text
读图 → ROI/预处理 → 阈值分割 → connection → 特征筛选 → 排序/统计 → 显示与记录
```

## 每日任务

### 第 1 天：固定与自动阈值

对同一图像使用 `threshold`、`binary_threshold`、`auto_threshold`。记录阈值来源、目标极性、区域面积和对亮度变化的敏感程度。

### 第 2 天：动态与局部阈值

使用 `dyn_threshold`、`var_threshold` 处理背景不均或局部对比目标。重点理解参考图、偏移量和明暗极性。

### 第 3 天：连通与筛选

使用 `connection` 拆分目标，再按面积、宽高、矩形度或圆度筛选。每加一个条件，都写清它排除了哪类干扰。

### 第 4 天：几何特征与排序

获取 `area_center`、`smallest_rectangle1`、`smallest_circle` 等特征，并用 `sort_region` 形成稳定顺序。

### 第 5 天：压力测试

模拟变亮、变暗、局部阴影和噪声。至少处理 30 张或 3 组亮度条件，统计正确计数、漏检、误检和耗时。

### 第 6 天：周项目

实现硬币、螺母或其他零件计数。输出总数、每个目标的面积/中心/类别，并用不同颜色显示合格目标和被排除目标。

## 验收标准

- 能稳定获得目标区域并过滤大部分杂点。
- 能说明固定、自动、动态、局部阈值的适用场景。
- 每个筛选特征都有明确物理意义，不堆叠无效条件。
- 在亮度变化测试中记录漏检、误检，而不是只展示成功图片。
