# 第 2 周练习任务

建议按顺序创建并完成：

1. `01_color_channels.hdev`：拆分、显示并重组 RGB 通道。
2. `02_domain_and_crop.hdev`：比较定义域、尺寸、坐标与耗时。
3. `03_filter_comparison.hdev`：均值、高斯、中值滤波对比。
4. `04_illumination_correction.hdev`：灰度拉伸、增强和光照校正。
5. `05_parameter_benchmark.hdev`：批量图片与参数计时。
6. `06_week_project_preprocess.hdev`：输出推荐结果和实验摘要。

每个程序至少包含：输入检查、原图显示、结果显示、关键参数文字、耗时、异常处理和 TODO 结论。
