## 直方图是什么

对于 byte 灰度图，横轴通常是灰度值 `0～255`：

```text
0                 128                 255
黑                 灰                  白
```

纵轴表示对应灰度值出现的像素数量。

- 分布集中在狭窄范围：图像通常对比度较低。
- 分布覆盖较宽范围：图像通常对比度较高。
- 分布整体靠左：图像可能偏暗。
- 分布整体靠右：图像可能偏亮。

## 程序流程

练习程序先把原图灰度压缩到较窄范围：

```text
scale_image (Image, LowContrastImage, 0.3, 80)
```

大致变换关系为：

```text
新灰度 = 原灰度 × 0.3 + 80
```

然后测量最小、最大灰度：

```text
min_max_gray (FullDomain, LowContrastImage, 0, MinLow, MaxLow, RangeLow)
```

最后计算线性拉伸参数：

```text
ScaleFactor := 255.0 / RangeLow
Offset := -MinLow * ScaleFactor
scale_image (LowContrastImage, EnhancedImage, ScaleFactor, Offset)
```

这会把原来的有效灰度范围近似映射到 `0～255`。

## 实验二：观察异常值影响

`min_max_gray` 的百分比参数为 `0` 时使用全部像素，少量极亮或极暗异常点可能影响拉伸范围。可尝试：

```text
min_max_gray (FullDomain, LowContrastImage, 1, MinLow, MaxLow, RangeLow)
```

比较参数 `0` 与 `1` 的结果。这里的百分比用于忽略灰度分布两端的一小部分像素。
