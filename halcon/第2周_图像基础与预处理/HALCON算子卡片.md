# 第 2 周算子卡片

| 算子 | 作用 | 关键点 | 常见问题 |
|---|---|---|---|
| `rgb1_to_gray` | RGB 转灰度 | 适合不依赖颜色的任务 | 颜色差异可能在灰度化后丢失 |
| `decompose3` | 拆分三通道 | 比较各通道对比度 | 不要默认某个通道总是最好 |
| `compose3` | 合成三通道 | 通道尺寸必须一致 | 通道顺序错误导致颜色异常 |
| `reduce_domain` | 限制图像定义域 | 便于 ROI 内处理 | 不等于真正裁剪像素矩阵 |
| `crop_domain` | 裁剪到定义域外接范围 | 输出坐标会变化 | 后续坐标需要正确换算 |
| `scale_image` | 线性灰度变换 | `Mult`、`Add` | 饱和截断会丢失细节 |
| `mean_image` | 均值平滑 | 核宽、核高 | 核过大导致边缘模糊 |
| `gauss_filter` | 高斯平滑 | `Sigma` | 平滑过度影响细边缘 |
| `median_image` | 中值滤波 | 掩膜形状、半径 | 对随机噪声未必最优 |
| `emphasize` | 局部增强锐化 | 掩膜尺寸、增强因子 | 噪声也会被增强 |
| `illuminate` | 校正缓慢变化照明 | 大尺度掩膜 | 尺度过小会损伤目标 |
| `gray_histo` | 统计灰度直方图 | 在指定区域统计 | ROI 不合理会污染统计 |
