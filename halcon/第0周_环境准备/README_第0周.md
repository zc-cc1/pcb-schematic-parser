# 第 0 周：环境准备（1～2 天）

## 目标

完成 HALCON 与 HDevelop 环境自检，能找到官方示例、示例图片和算子帮助，并建立统一的学习与测试习惯。

## 第 1 天：环境自检

1. 启动 HDevelop，确认版本和许可证状态正常。
2. 打开任意官方示例，完整运行、单步运行并设置断点。
3. 在程序、图形、图标变量、控制变量和算子窗口之间切换。
4. 在算子帮助中找到参数顺序、可选值、复杂度说明和相关示例。
5. 找到 HALCON 示例程序与示例图片目录，记录实际路径。

## 第 2 天：目录与数据约定

1. 阅读根目录的 `README_学习目录.md` 和 `HALCON学习计划.md`。
2. 明确每周的 `练习代码`、`学习记录`、`data`、`output` 用途。
3. 选择 5～20 张自己的图片作为第 1 周批量浏览素材。
4. 确认中文路径、空格路径和只读路径是否能正常读取。
5. 完成 `环境检查表.md`。

## 验收标准

- 能独立打开并运行一个官方示例。
- 能单步、断点并查看图标变量与控制变量。
- 能从帮助文档定位一个算子的参数说明和对应示例。
- 能说出原图、调参结果、测试结果分别应该放在哪里。
