# 第 10 周练习任务

1. `01_bar_or_data_code.hdev`：选择一种码制完成模型创建、查找与释放。
2. `02_text_roi_segmentation.hdev`：文本 ROI、预处理和字符分割。
3. `03_ocr_recognition.hdev`：字符分类、顺序、置信度和字符串拼接。
4. `04_format_validation_ocv.hdev`：格式规则或 OCV 验证。
5. `05_recognition_stress_test.hdev`：多种干扰与失败归档。
6. `06_week_project_code_or_ocr.hdev`：完整读取、验证、统计流程。

失败记录要区分：未定位、分割失败、分类错误、低置信度、格式不合法和模型异常。
