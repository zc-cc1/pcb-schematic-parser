# 第10周每日代码索引

示例使用 HALCON 自带条码、二维码和 OCR 素材，不需要联网下载。识别结果为空时先检查图像质量、ROI、码制和模型参数。

| 天数 | 文件 | 本日重点 |
|---|---|---|
| 第1天 | `练习代码/01_read_bar_codes.hdev` | 一维码创建、识别与释放 |
| 第2天 | `练习代码/02_read_qr_code.hdev` | QR Code 识别及结果轮廓 |
| 第3天 | `练习代码/03_segment_ocr_characters.hdev` | 点阵字符分割与排序 |
| 第4天 | `练习代码/04_recognize_ocr_characters.hdev` | 调用预训练 MLP 字库 |
| 第5天 | `练习代码/05_validate_decoded_format.hdev` | 长度、前缀和正则校验 |
| 第6天 | `练习代码/06_week_project_code_or_ocr.hdev` | 条码与二维码综合识别项目 |

第3、4天的字符分割参数针对 `needle1`。换成自己的图片时，应先重新确定 ROI、二值化阈值和字符尺寸范围。
