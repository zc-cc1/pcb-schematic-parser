# HALCON 第 4 周：形态学与几何变换

本周总目标：使用形态学修复或清理区域，并通过二维仿射变换把旋转、平移或缩放目标变换到统一位置。

## 本周安排

| 天数 | 主题 | 主要成果 |
|---|---|---|
| 第 1 天 | 膨胀、腐蚀 | 理解结构元素与目标尺寸关系 |
| 第 2 天 | 开、闭、填孔 | 清噪、断裂修复、孔洞处理 |
| 第 3 天 | 形状转换与区域质量 | 建立处理前后特征对比 |
| 第 4 天 | 平移、旋转、缩放矩阵 | 生成并组合二维变换 |
| 第 5 天 | 图像与区域变换 | 对齐目标和检测 ROI |
| 第 6 天 | 周项目 | 区域修复与姿态归一化 |
| 第 7 天 | 复盘 | 总结过度腐蚀和粘连风险 |

## 核心概念

- 结构元素的形状和尺寸应与要去除、连接或填补的缺陷尺度匹配。
- 开运算倾向于去掉小前景和细连接；闭运算倾向于填补小间隙和连接邻近前景。
- 形态学会改变几何尺寸，测量前必须验证偏差。
- HALCON 常用图像坐标为行、列；旋转中心、角度方向和弧度单位必须核对。
- 同一个姿态变换要一致地应用到图像、区域、轮廓或检测 ROI。

## 每日任务

### 第 1～2 天：形态学

对含小噪点、断裂、孔洞和粘连的区域，分别测试膨胀、腐蚀、开、闭和 `fill_up`。每种操作至少测试 3 个半径，记录面积和轮廓变化。

### 第 3 天：质量验证

使用 `area_center`、外接矩形或圆度对比处理前后区域，说明操作是否破坏真实目标。尝试 `shape_trans` 获取凸包或规则包围形状。

### 第 4 天：变换矩阵

从单位矩阵开始，依次加入平移、旋转和缩放。对同一点手算或打印变换前后坐标，检查变换顺序的影响。

### 第 5 天：统一姿态

将一个旋转零件校正到标准方向，同时变换检测 ROI。验证 ROI 是否仍覆盖同一物理位置。

### 第 6 天：周项目

输入多姿态零件图，先分割并修复区域，再估计姿态并归一化。输出原始区域、修复区域、校正图像和跟随 ROI。

## 验收标准

- 能根据缺陷尺度选择结构元素，而不是随意调半径。
- 能指出过度腐蚀、过度膨胀和相邻目标粘连的表现。
- 能将目标变到标准位置，并正确变换检测区域。
- 能解释平移、旋转、缩放顺序为什么影响结果。
