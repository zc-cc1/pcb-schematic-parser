# 第 4 周算子卡片

| 算子 | 作用 | 关键点 | 常见问题 |
|---|---|---|---|
| `dilation_circle` | 圆形结构元素膨胀 | 半径匹配间隙尺度 | 目标粘连、尺寸增大 |
| `erosion_circle` | 圆形结构元素腐蚀 | 去小连接或边缘 | 细目标消失 |
| `opening_circle` | 先腐蚀后膨胀 | 去小前景、断开细连接 | 真实细节被删除 |
| `closing_circle` | 先膨胀后腐蚀 | 填小缝、连断裂 | 邻近目标被合并 |
| `fill_up` | 填充区域孔洞 | 适合封闭区域 | 真正的孔特征会丢失 |
| `shape_trans` | 区域形状转换 | 凸包、矩形、圆等 | 转换形状不等于真实边界 |
| `hom_mat2d_identity` | 创建单位矩阵 | 所有变换的起点 | 忘记初始化矩阵 |
| `hom_mat2d_translate` | 加入平移 | 行列与 X/Y 对应需核对 | 方向写反 |
| `hom_mat2d_rotate` | 加入旋转 | 弧度、旋转中心 | 角度单位或中心错误 |
| `hom_mat2d_scale` | 加入缩放 | 比例与缩放中心 | 非等比缩放改变形状 |
| `affine_trans_image` | 仿射变换图像 | 插值方式、输出适配 | 插值影响灰度和边缘 |
| `affine_trans_region` | 仿射变换区域 | 使用同一矩阵 | 与图像使用不同矩阵导致错位 |
