# 导线（10%）分割质量调查：今天试了什么、天花板在哪

日期：2026-10-20
基线：A3_pin_l1 + 导线 0.35 + 引脚 0.60 + 断口桥接 8px = **70.33**（13 页 open_GT，平台口径）

## 1. 先量清楚：模型到底看没看见线

把真值的 744 条线段按 3px 宽栅格化，直接问 U-Net 的概率图：

| | 结果 |
|---|---|
| 真值墨迹 | 222,140 px |
| 概率 ≥0.35 覆盖 | **182,302 px = 82.1%** |
| 墨迹内平均概率 | 0.70–0.85（逐页） |

再看未覆盖那 18% 的像素颜色：**亮度 182–207、暗像素占比 7–14%**，而覆盖部分是亮度 73–106、暗像素 59–82%。也就是说未覆盖的主要是**我那 3px 笔画的背景边缘**，不是真的导线。

**结论：掩膜几乎不瞎，线基本都"看见"了。**

## 2. 那为什么只对上 26%？

把 331 条未命中的预测段，投影到最近的真值线上：

| 情况 | 占比 |
|---|---:|
| **比真值线长**（两端越界 >4px） | **86.1%** |
| 完全落在真值线内部（被切碎） | 11.8% |
| 比真值线短 | 2.1% |

端点沿线的偏移集中在 0–10px（最大到 ±30px）。**同一片墨迹，我们切的位置和真值不同** —— 真值在引脚、网络节点处切；我们的骨架只在骨架分叉处切。

## 4. 天花板

在当前最好配置上做"完美网络切分"（每条预测段都允许匹配最合适的真值段，作弊级）：

| | 导线 |
|---|---:|
| 现状 | **2.86 / 10**（F1 .2855，tp 185 / fp 367 / fn 559） |
| 完美切分 | **3.41 / 10**（tp 221） |
| 提升空间 | **+0.55** |

而且我们画的 552 段里只有 221 段（40%）真的落在某条真值线上，GT 744 段只覆盖 221 段（29.7%）。

## 5. 结论

- **导线这条线的可操作空间约 +0.55**，已经拿到其中 +0.95（桥接）+0.10（切分），剩下的要靠"切点与真值完全一致"。
- 但真值的切点是 CAD 网络节点（引脚、junction、网络标号锚点），**图像上没有直接证据**能推出它为什么在那里切 —— 继续调骨架参数的边际收益很低。
- 另外，12 页里有一半页面我们的**段数比真值多**（case 6: 21 vs 86 少、case 13: 25 vs 11 多），说明"切多切少"本身是双向误差，不存在一个全局最优的切分粒度。

**建议：导线到此为止（2.86/10），把精力转到连通（35% 权重，现值 .5945，空间约 14 分）。**
导线与连通的逐例相关系数只有 0.48，改连通不会自动改导线，但连通的池子大 25 倍。
