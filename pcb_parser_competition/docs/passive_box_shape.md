# 被动元件框：按引脚方向定向 + 向检测框生长（12/13 从此不再是黑洞）

日期：2026-10-18
改动：`D:\pcb5_submission\agent.py` 新增 `_shape_passive()`，两个开关默认开
效果：component 0.706 → **0.727**，总分 54.20 → **54.82**；case 12 组件 0.222 → **0.333**，
case 13 组件 0.105 → **0.368**

## 1. 之前为什么修不动

案例 13 的每一个被动件都**只差一点点**：参考框 23×58，我们写 8×20，坐标差 21–29px，
刚好越过 20px 红线。案例 12 更糟：电阻画成横向（参考 52×26），我们却写成了竖向 8×20。

两次失败的经历（都已记录）：

| 尝试 | 结果 | 原因 |
|---|---|---|
| 全局放大 canonical 框（×1.5/×2.5） | open_GT +0.036，但 10 页 Golden 0.24 → 0.02 | 两套数据的框约定相反 |
| 用"检测框 × k"替换 | 离线 +0.02，端到端 −0.011 | 管线拿到的是融合框，不是原始检测框 |
| 用"两脚 tip 包围盒"替换 | 0.706 → 0.495 | tip 常常连到很远的导线端点 |

## 2. 这一版做了什么

两件事，都不需要 GT：

1. **方向用引脚定**：一个两端元件的主轴由它两个引脚点的连线的长边决定。检测框可能因为
   符号画得扁而被判成竖向（案例 12 的电阻），引脚连线不会骗人。方向不一致时，把 canonical
   尺寸绕中心转 90°。
2. **向检测框生长，但有上限**：canonical 框只向检测框方向扩张，每边最多 `0.75 ×` 自身尺寸。
   上限是必须的——无上限时 0.706 → 0.537（把邻居也吞进来了），上限 0.5–0.75 是平台期。
