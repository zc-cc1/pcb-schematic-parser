# 四项分数之间的连带关系：怎么隔离，以及一个被实测否定的方案

日期：2026-10-19
结论先说：**"放宽出口让上游的缺失流到下游"是错的**——实测总分 −2.04。
正确的隔离方向不是放宽传递，而是**分层只写有证据的东西**，并把"证据质量"提上去。

## 1. 分数是一条链，不是四份独立成绩

```
元件 key（位号）
   └─→ 引脚号 ─→ 网络成员 ─→ 导线端点
```

| 层 | 平台比法 | 上游缺了会怎样 |
|---|---|---|
| 元件 | key + type + bbox≤20px | **最致命**：key 没了，它的引脚、连通、导线全部归零 |
| 引脚 | key + `pin_<号>` + 名字精确 + 点≤20px | 号缺 → 该引脚 0 分；名字缺 → 该引脚 0 分 |
| 连通 | 每条网络当集合，软 F1 | 成员少一个 → 该网少一分交集；**但名字不影响连通**（顶点是 (元件, 号)） |
| 导线 | 只在已匹配的网内比线段 | 网没匹配上 → 该网所有线段都丢 |

**关键结构性事实**：连通顶点 = `(元件 key, 引脚号)`，**名字不进顶点**。
所以"名字错"只伤引脚项，不伤连通。

## 2. 现在的阻塞点（一次 kept-work 全跑的真实统计）

| 出口被扣的原因 | 候选数 | 影响 |
|---|---:|---|
| `component_identity_unresolved`（没有归属元件） | 249 | **无法表达**，只能靠位号/框检出来解决 |
| `pin_number_unresolved`（没有号） | 144 | 引脚项 + 连通同时丢——**当前唯一的真实连带** |
| `pin_name_unresolved`（有号无名） | 47 | 只影响引脚项 |

被扣的网络原因：`no_resolvable_member` 63 条、电源未挂成员 11 条、电源逻辑合并 11 条。

我们导出的网尺寸分布：**1 个成员 163 条**、2 个 54 条、3 个 17 条、4+ 14 条。
（平台**不把 1 成员网计入**——那 163 条是白干的。）

## 3. 实测：把"名字缺失"放行，分数变差

改了 1 行（`PCB_PIN_NAME_OPTIONAL=1`：允许有号无名的 IC 引脚导出），13 例全跑：

| 配置 | comp | pin | conn | wire | 总分 |
|---|---:|---:|---:|---:|---:|
| 名字必需（现役） | 0.885 | **0.833** | **0.411** | **0.422** | **65.96** |
| 名字可缺（放开） | 0.885 | 0.811 | 0.381 | 0.377 | 63.92 |

**−2.04 分。** 为什么连通也掉了？因为多出来的那些"半成品"引脚：
- 引脚项：名字错 = 直接算假阳性（**比不写更差**：不写只是漏，写错是漏 + 多一个错）；
- 连通：它们的号有一部分是错的，塞进网络后既不是交集、又撑大分母；
- 导线：网变脏，匹配到的参考网变少。

**结论：半成品实体自带噪声，放宽出口等于把噪声灌到下游。**

## 4. 所以"隔离"应该怎么做

### 4.1 认清"缺"和"错"的代价不对称

| 情况 | 该参考项 | 我们 |
|---|---|---|
| 不写 | 算 fn（漏） | 无额外惩罚 |
| 写错 | 算 fn（漏） | **多一个 fp** |

所以**精确匹配项（元件/引脚/导线）的正确策略是"宁可少写，不可写错"**。
这和我之前"写错等于不写"的说法相反，实测已经证明（名字放开 −2 分）。

### 4.2 三个真正能隔离的地方

**① 元件层：key 完整度是唯一总闸（已做到 0 缺失）**
只要检出的元件都有 key，它的引脚/连通/导线就都还有机会。这一层我们已经修到 0 缺失——
这也是第 9 次评测里元件、引脚逐位与平台一致的原因。

**② 网络层：成员要"少而准"（已做部分）**
现在的 `partial members` 允许"成员不全就导出"，方向是对的（软 F1 会给部分分）。
但反过来要加一条：**成员数 < 2 的网不该导出**（平台不计，还占匹配名额）。
163 条单成员网 → 建议直接不发。

**③ 引脚层：把"缺"变成"有"，而不是"放行"**
- 名字缺：**用库补**（型号已知时，库的 (号→名) 是准的），不要放行；
- 号缺：**窄带读号**（已做，只补未进网的），继续扩大覆盖——这是唯一同时提 pin 和 conn 的来源。

### 4.3 一个可以试的"名额隔离"

平台的连通用匈牙利一对一匹配：**一条"成员错得多"的预测网可能抢走一个本可被正确网匹配的参考网**。
可以做**网级置信度过滤**：只导出"至少 2 个成员、且每个成员都不是弱证据"的网。
预期：连通精度上升、少抢名额；代价是少数"部分正确"的网被放弃。

这个可以先用本地算器（已校准到 0.1 分内）做 A/B，再决定。

## 5. 一句话

> 四项不是独立打分，而是共用一条身份链；**上游缺什么，下游就少什么**——
> 但"把缺的硬塞过去"会更糟（实测 −2 分）。
> 能隔离的是**出口的取舍**（少而准），不能隔离的是**证据本身**（得靠识别）。
