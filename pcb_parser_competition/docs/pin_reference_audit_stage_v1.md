这些是字段复核计数，不是独立测试、OCR准确率或官方PinF1；字段可能来自OCR、引脚库或候选格式约定。一个pin可以有两个字段条目。

S18新增11字段中3个与匹配草稿字段一致、3个草稿缺字段、5个同器件坐标超5px。5个超限案例的器件都能匹配，分别为：C87编号2距离9.374px，U6编号3距离5.147px，LD1编号12距离11.198px，LD2名称F距离10.471px，LD2编号11距离12.375px。既有5px规则保持，最近同字段参考只用于寻找人工复核线索。

0170数码管草稿把型号FJ2381AH写入右上引脚编号、把下一行可见编号11记为1，存在字面问题；其参考点与预测点在沿引线方向也有差异。U6编号3略超阈值，模型点与参考点相对印刷引线的位置需另行确认。以上都没有自动改参考、吸附坐标或增加命中数。

全部字段的唯一一对一占用案例是0018/U3：`PIN_CAND_0102`的编号8和`PIN_CAND_0113`使用同一个参考引脚附近的两个预测点。这是一项后续复核任务，不能仅凭参考距离合并模型点或转移字段。

产物位于`runs/s19_pin_reference_audit/`：

- `all_emitted_field_diagnostics.json`：逐字段归因、最近同器件参考、最近同字面参考、参考占用者。
- `new_field_review.json`：S18新增11字段的对照图索引。
- `audit_*.png`：局部放大加器件上下文，红圈是预测，蓝叉是参考，橙框是OCR字框。
- `review_sheet_1.png`至`review_sheet_3.png`：11张对照图概览。
- `audit_summary.json`：输入PNG、字段、图、出口、参考和配置哈希及未变校验。
- `report.md`：逐例距离与限制说明。
