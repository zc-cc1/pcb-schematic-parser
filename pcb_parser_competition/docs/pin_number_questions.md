# 待确认的引脚编号与电源规则

以下为可向赛题方核对的问题草稿，没有对外发送。

1. PNG中的无文字对称R/C元件如何确定pin_1、pin_2？是否有官方元件库的方向/旋转规则，或允许等价的两端置换？
2. 赛题提及缺失编号自动生成。Golden采用何种顺序：源CAD pin ID、空间顺序，还是提交者自行编号？PNG无法恢复源ID排序时如何评分？
3. 无独立引脚名的R/C/L/晶振应将pinname设为编号、空字符串还是其他名称？第25页R1示例的“1”是否为通用规定？
4. GND/VCC电源符号的tip具体落在图形哪个位置？重复符号的component后缀如何从PNG确定，同名电源的逻辑作用域与普通飞线是否不同？

当前本地策略：未知编号保留未决；少量可见数字由OCR恢复；被动器件“编号作pinname”仅存在开发候选出口。原始CVJsonStd没有可靠的R/C编号对，不能把本地自动编号视为官方答案。
