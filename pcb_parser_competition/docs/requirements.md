## 暂定导出契约

组件字段采用实际 JSON 图中的 `Name`（p13），不是表格偶尔出现的小写 name；顶层采用 `components`，不是 p10 正文中的单数 component。正式 Golden/评测器到位后再确认并版本化修改，禁止偷偷兼容到评分字段上。

`schemas/submission.schema.json` 是本项目的暂定结构规范，不是官方评分实现；保留任意非空 type，尚未锁定类别枚举。它只能描述结构，不能证明图像识别正确。引用存在性、bbox 顺序、坐标范围、重复键、网归属等需要后续语义校验器。

空预测可能结构合法但无识别成绩。现阶段不产生“通过官方评测”的结论。

## 内部坐标

内部：原图像素、左上原点、x 右/y 下。每个裁剪/切片保存完整变换；骨架 row/column 在适配层转换成 x/y。正式输出：左下原点、x 右/y 上。

转换器当前明确采用 H−y 作为本地坐标约定，并在报告中标记未获Golden确认；可通过配置或 `--y-origin height_minus_one` 重建为 H−1−y。正式出口约定仍须拿同一 PNG 的 Golden 点验证。坐标容差不是断线补连或 pin 接触的默认阈值。

## 阶段指标

S0：资料逐项有路径/版本或缺失状态；关键歧义有来源和核验动作；禁止用截图或无来源 JSON 充当正式两例。S1：至少一个中等和一个困难例真实推理、合法导出、保存四项官方指标或明确 proxy 状态。后续 F1 目标来自开发计划，尚无实测。
