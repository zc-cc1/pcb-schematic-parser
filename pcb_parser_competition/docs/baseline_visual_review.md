# 首轮预测的人工复核

2026-10-11，已查看 `runs/s1_gpu_baseline/0002/cuda_0/sliced/overlay.png` 和 `0001/cuda_0/sliced/overlay.png`。以下是图像复核发现，不是官方评测结果。

0002：检测器输出4个电容、4个接地符号。IC2 的矩形芯片、X2 晶振以及 C74/C86 两个竖向电容没有检测框。晶振不在该开源权重的10类中，需要补充类别/训练。OCR 输出54个区域，图中可见 IC2、BCM2835、X2、19M2、C74、C86 及引脚文字；存在文字候选，并不表示位号、模型与引脚关系已正确解析。

0001：SAHI 的 GPU 候选数从整图57个增加到107个，待复核其类别、框范围和重复框。CPU 切片结果为105个，GPU 为107个，这两处差异的具体原因尚未定位；不得将候选数增加解释为召回率提升，也没有承诺 CPU/GPU 结果逐字段一致。

OCR 的密集图耗时约6.31秒，超过本轮 GPU 检测约0.14秒。检测器加速已确认；全流程优化仍需单独处理 OCR，后续可测 GPU OCR 或按区域运行 OCR，再比较文字质量和总耗时。

当前位号绑定采用兼容类别与矩形距离，并拒绝距离接近的候选；0002 暂绑定4个，0001 切片暂绑定30个。这些绑定仍需复核。Name、value、引脚与网络尚未实现，`components_partial.json` 不是完整比赛答案。

下一步优先复核一批 Dataset300 的类别和检测框，划分训练/验证集时隔离重复图及同源工程，再针对竖向器件、晶振、矩形 IC、小尺寸符号进行检测微调。随后改善 OCR 的位号/型号/数值绑定，并接入引脚、导线骨架和网络规则。
