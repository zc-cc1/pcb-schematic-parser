# 电源逻辑连接候选阶段

新增独立入口 `scripts/run_power_networks.ps1`。它从原始 PNG 依次执行冻结的 YOLO/SAHI、U-Net、RapidOCR、S14准确型号引脚库，再生成同名电源逻辑连接候选。原 S12 默认入口和 S14 试验入口均保留。

只使用同一张图里的**实际完整文字＋检测电源符号＋唯一已接线U-Net引脚点**。文字须同位置至少3种OCR视图、每种置信度至少0.98。视图来自同一模型，不当成独立证据。只按完整字面名称比较，GND/DGND/AGND、不同大小写或VCC_3.3/3V3不合并。

缺/多归属tip、引脚接线不唯一、两种强视图支持另一拼写、网络有不同电源名、未决交点、断线、漏电源成员风险或普通飞线混入，均保留待决。没有文字的GND图形不默认归入GND。

电源合并是内部网络成员关系；所有原引脚、字段、归属及线段原样保留，相关网络的其他成员也全部保留。不新增远距离物理导线，不把电源当成普通飞线或生成零长度飞线edges。不推断重复电源组件的源ID顺序，不补电源编号或pinname。

```powershell
.\scripts\run_power_networks.ps1 -Image .\data\standardized\0018\0018.png -Device cpu
```

主要输出：

- `power_graph_proposals.json`：内部电源逻辑连接候选，原网络到新网络的对应及全部成员。
- `power_binding_audit.json`：每处文字证据和每组接受/未接受的原因，236处电源组件的复核队列。
- `baseline_export`、`proposal_export`：旧/新部分JSON及逐网络字段缺口。所有新电源组显式标为provisional，禁止作为完整赛事net导出。

同一26页旧开发数据中，28处节点满足证据门槛，形成3组候选，减少9个网络分组：0018的5处GND、0029的2处PVDD、0105的5处GND。新图保留1477个原引脚、全部物理边和所有原网络成员；严格部分JSON仍116个字段齐全pin、0个net，候选仍131个pin、1个net。

成对参考扩展为“原普通标签草稿＋源注释中有唯一明确文字的电源分组”，不按缺失文字的Gnd类别自动合并。两种模型结果均用同一新参考评估：已匹配归属/5px位置的连接对F1为51.92%→56.05%；全量配对代理F1为23.38%→25.41%。条件TP增加65、FP仍3；全量代理FP增加43。这不是官方NetF1或独立测试，不能直接与此前物理/普通标签参考分数混比。

运行时不读取源标注、CAD或参考。只有离线评估脚本读取它们；原注释和训练数据不修改。本轮没有训练，原权重冻结。三个应用候选组的助手视觉复核仅核验显示的文字与符号角色，未认证完整远端成员路径，记录在 `data/reviews/power_networks_v1.json`，不进入推理或训练。
