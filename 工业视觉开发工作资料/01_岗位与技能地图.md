# 工业视觉岗位与技能地图

## 1. 工作内容的真实边界

公开岗位样本普遍把机器视觉工程师的职责写成六类：

1. 对接客户或工艺人员，定义检测对象、缺陷标准、节拍和接口。
2. 选择并验证相机、镜头、光源、控制器和工控机。
3. 用 HALCON、VisionPro 或 OpenCV 完成定位、测量、缺陷检测、OCR/读码等算法。
4. 用 C#、C++ 或 Python 开发上位机并接入相机 SDK。
5. 与 PLC、机器人和运动控制系统通讯联调，处理 TCP/IP、Modbus 等接口。
6. 完成现场调试、文档、验收、培训和售后。

这说明岗位本质上是“光、机、电、算、软”的系统工程。算法重要，但成像稳定性、异常恢复和现场沟通同样决定项目是否成功。

## 2. 能力矩阵

| 能力域 | 入门应会 | 可独立项目 | 进阶方向 |
|---|---|---|---|
| 需求与工艺 | 区分 OK/NG，记录视野、精度、节拍 | 能把模糊描述转成可验收指标；设计样品计划 | 可行性、风险、成本和交付周期评估 |
| 相机 | 分辨率、像元、帧率、曝光、增益、单色/彩色 | 面阵/线阵选择；软/硬触发；丢帧排查 | GigE/USB3/CoaXPress、多相机同步 |
| 镜头 | 焦距、工作距离、视野、景深、光圈 | 传感器靶面匹配；畸变与远心镜头判断 | MTF、倍率、景深与测量不确定度 |
| 光源 | 环形、条形、背光、同轴、穹顶的用途 | 针对反光、划痕、轮廓和透明件做对比实验 | 偏振、多光谱、频闪与光学结构设计 |
| 经典视觉 | 阈值、形态学、边缘、轮廓、模板匹配 | 定位后 ROI 跟随、测量、OCR、缺陷差分 | 鲁棒性、亚像素、复杂背景和速度优化 |
| 标定与测量 | 像素和毫米换算；畸变概念 | 内参/外参、平面测量、重复性验证 | 双目、手眼标定、多坐标系链路 |
| 编程 | C# 或 C++ 基础、调试、文件与异常 | 多线程采集/处理、配置、日志、状态机 | 模块化平台、性能、单元/集成测试 |
| 自动化集成 | Socket、串口、Modbus 基础 | 触发握手、结果回传、超时重试、报警复位 | PLC/机器人/运动控制和安全互锁 |
| 数据与验证 | 保存原图、结果图、参数和时间戳 | 开发/调参/测试集隔离；统计误判漏检和耗时 | 批次漂移、数据闭环、可追溯和版本管理 |
| 现场能力 | 按清单接线和排查 | 从光学、机械、网络、软件分层定位故障 | 标准化交付、远程维护、跨团队推动 |
| 文档与沟通 | 能读英文手册，写操作步骤 | 输出方案、I/O 表、调试记录、验收报告 | 技术评审、客户培训与风险管理 |

## 3. 学习优先级

### 必须先掌握

- 成像基础：视野、工作距离、分辨率、曝光、增益、景深、畸变和光源方向。
- HALCON 基础流程：采图/读图、ROI、预处理、分割、区域/轮廓、匹配、测量、标定。
- 一门交付语言：当前建议 C#；会写稳定的采集、处理、显示、配置、日志和异常恢复。
- 相机 SDK：枚举设备、打开、参数设置、软/硬触发、缓冲区、图像回调、停止与释放。
- 工业通讯：先学 Socket 和 Modbus TCP，再根据目标公司补西门子 S7、Profinet、EtherNet/IP 等。
- 验证方法：保留失败样本；测试不同批次、位置、角度、亮度、速度和连续运行。

### 第二阶段再学

- 深度学习缺陷检测、目标检测与分割。
- 3D 点云、结构光、ToF、激光轮廓和机器人手眼标定。
- C++ 性能优化、GPU/ONNX/TensorRT、边缘设备部署。
- 多相机同步、线阵高速采集和复杂运动控制。

## 4. 当前工作区最适合的路线

现有资料已经覆盖 HALCON 20.11 的 12 周训练和多类工业相机手册，因此建议路线是：

1. 以现有 HALCON 目录完成经典算法基本功。
2. 同步选一份 GigE 面阵相机手册，学习曝光、增益、触发、I/O、像素格式和网络参数。
3. 用 C# 做一个相机抽象接口和检测流程状态机。
4. 用 Modbus TCP 模拟器实现“触发—检测—结果—复位”握手。
5. 做一个完整测量项目和一个缺陷项目，再决定算法/3D 分支。

## 5. 常见误区

- 只学 YOLO：规则稳定、边界清晰的任务常常用传统视觉更快、更可解释。
- 只看最终图：没有原图、失败样本、参数和指标的项目不可复现。
- 用自动曝光跑产线：画面会随工件改变，阈值和测量随之漂移；调好后通常要锁定关键参数。
- 先调算法后解决反光：成像问题应优先用光学和机械方式解决。
- 只跑几十张图：应覆盖批次、时间、温度、速度、振动、污渍和极限样品。
- 只做 UI：漂亮界面不能替代状态机、错误码、日志、重连、权限和参数版本管理。
