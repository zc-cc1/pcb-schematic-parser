## 2. 上电前检查

- [ ] 相机、镜头、光源、支架固定，无松动和碰撞风险。
- [ ] 电源、电压、极性、接地和 I/O 电平正确。
- [ ] 网线/USB 线缆、网卡、IP、子网、巨帧等配置已记录。
- [ ] 光源散热、频闪占空比和触发接线符合规格。
- [ ] 工控机磁盘空间、时间同步、自动启动和权限已确认。
- [ ] PLC/机器人处于允许联调的安全状态，互锁有效。

## 3. 成像基线

- [ ] 保存一组原始基线图，不带任何算法绘制。
- [ ] 曝光、增益、白平衡、Gamma、像素格式、ROI、帧率已记录。
- [ ] 关键参数在调试完成后锁定；明确哪些允许配方修改。
- [ ] 检查运动拖影、饱和、噪声、反光、景深、畸变和环境光影响。
- [ ] 使用 OK、典型 NG 和边界样品确认对比度。

## 4. 触发与采集

- [ ] 单次触发只生成预期数量的图像。
- [ ] 验证触发延时、曝光时间、闪光时序和运动位置。
- [ ] 记录采图超时、丢帧、缓冲区溢出和帧序号异常。
- [ ] 重复触发、过快触发、相机断线时有明确错误码和恢复策略。
- [ ] 停止、关闭和重启不会残留占用或错误状态。

## 7. 故障分层排查

按下列顺序记录，不要一上来改算法阈值：

1. 工件与工艺：样品、姿态、污染和上游变化。
2. 光学与机械：光源、遮光、焦距、光圈、支架、振动和工作距离。
3. 相机与采集：曝光、增益、触发、带宽、线缆、缓冲区和驱动。
4. 标定与坐标：标定板、图像覆盖、重投影误差、坐标链和机械零位。
5. 算法与数据：ROI、参数、训练数据、版本和失败样本。
6. 软件与通讯：线程、状态机、超时、PLC 地址、日志和系统资源。
