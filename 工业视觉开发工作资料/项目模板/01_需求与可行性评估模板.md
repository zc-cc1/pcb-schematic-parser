# 工业视觉需求与可行性评估模板

## 1. 基本信息

- 项目/工位：
- 产品型号：
- 联系人（工艺/机械/电气/软件）：
- 评估日期与版本：
- 预计交付日期：

## 2. 检测任务

- 检测对象和材质：
- 检测内容（定位/测量/缺陷/OCR/读码/引导）：
- OK 定义：
- NG 定义：
- 最小缺陷或最小特征：
- 缺陷边界样品是否经客户/质量确认：是 / 否
- 是否允许人工复判：
- 漏检和误杀的风险与允许上限：

## 3. 节拍与运动

- 单件节拍：
- 线速度/运动速度：
- 工件是否停止拍照：
- 触发来源与信号电平：
- 一件几张图、几个相机：
- 从触发到结果的最大允许时间：

## 4. 空间与环境

- 视野（宽 × 高）：
- 可用工作距离：
- 安装空间和禁入区：
- 工件位置/角度波动：
- 环境光、反光、粉尘、油污、振动、温度：
- 防护等级与清洁要求：

## 5. 精度与成像估算

- 相机候选分辨率：
- 物方像素分辨率 = 视野尺寸 / 对应方向像素数：
- 最小特征预计覆盖像素数：
- 镜头焦距、靶面、接口、畸变和是否需要远心：
- 光源类型、颜色、安装角度、是否频闪/偏振：
- 景深与工件高度波动是否满足：

说明：最小特征覆盖 1 个像素通常不能作为可靠交付依据。需要多少像素取决于对比度、噪声、算法、光学质量和工艺风险，必须以样片和重复性测试确认。

## 6. 样品与数据计划

- OK 数量、批次和边界样品：
- 各类 NG 数量、批次和严重程度：
- 是否覆盖位置、角度、亮度、速度、污渍和温度变化：
- 开发集、调参集、测试集如何按批次/时间隔离：
- 原图命名、产品 ID、时间戳和标签规则：

## 7. 接口与软件

- PLC/机器人/运动控制器品牌与协议：
- 触发、忙、完成、OK/NG、结果、复位、心跳地址：
- 相机型号、接口和 SDK 版本：
- 工控机、操作系统、运行库和授权：
- UI、配方、权限、日志、图像保存和数据库要求：
- 网络拓扑和 IP 规划：
