# 观察结点后的网络片段合并

入口：`agent.finalize_connectivity_recovery` 在既有导线几何校正后调用
`network_junction_reconcile.reconcile_network_junctions`。该阶段只读取当前图片、
同图模型图和导线几何阶段观察到的红色结点，不读取参考答案、页码、位号或固定坐标。

两个已有网络满足以下任一条件时，才提出合并：

1. 两条导出线段沿同一直线至少重合60像素，方向误差小于3度，垂距不超过2像素。
2. 两个网络各有一条线段沿墨迹走向接近同一实测红色结点，端点离结点不超过30像素，
   沿缺口的原图红/绿墨迹支持率至少95%。无红点的交叉不触发。

合并仅汇集原网络成员和现有几何边，去除同网络内端点相差不超过2像素的重复边；
元件、引脚和其他结果字段不变。每页最多接受8组合并，证据图的哈希、尺寸和坐标系必须匹配。
审计含每个候选的证据、保留的网络ID和参与合并的原网络ID。重复执行输出相同。

第13页原有17条导线漏检中，14条的几何线段其实已导出到其他网络；
同图结点与长线重合证据把这些片段归并后，导线TP/FP/FN由32/28/17变为46/13/3，
F1由58.72%升至85.19%，连通由67.14%升至87.53%，总分由82.871升至92.656。
其余12页的缓存预测逐字段相同。497项暂存测试、13页重复运行与13页完整缓存导出入口通过；
未重新运行整页模型，也未调用外部API。

剩余3条属于几何缺画或截断。曾测试把长线自动延伸到红点，虽能修复本页一条，
但会使第一页退分，因此暂不启用。
