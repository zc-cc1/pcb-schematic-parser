# 图像结构与连通修复

agent.py在引脚和类别修复之后调用finalize_connectivity_recovery。
配置：configs/connectivity_recovery_v1.json。PCB_CONNECTIVITY_RECOVERY=0关闭整个阶段。

规则包含：模型接点补挂网、完整支路恢复、对侧电感端点、箭头标签、独立LED拆分、
可见端点位置校正、重复OCR支持的电源接点、彩色导线/圆点/交叉重建、蓝字短缺口、
朝向元件外侧的红色短线及无导线碎片清理。

结构规则按依赖顺序生成草稿，由显式加载的ImageStructurePolicy校验后原子提交。
保护IC、开关和连接器的既有引脚与身份；不猜未知脚，不连接NC，不依赖真实位号、页码或参考答案。
当前图纸颜色需为红色符号、绿色导线、蓝色文字。元件数量、端点和网络均有预算限制。
只对重建的导线执行稳定化清理，重复运行须得到相同结果。

阈值和独立规则开关位于structural.patterns。端点/身份变动依赖后续拓扑重建，不能独立提交。
原先的图像模型和OCR结果可以复用；电源文字视图不足时，仅调用有预算的本地裁剪OCR。
日志包含规则版本、图像和输入哈希、候选、修改、拒绝原因和本地OCR模型指纹。

发布前：359项测试、13页冻结缓存回归及10页完整导出入口通过；第一页本地裁剪OCR复验一致。
100%网络顶点连通指标不代表所有物理导线都已识别正确，导线几何仍可单独优化。
