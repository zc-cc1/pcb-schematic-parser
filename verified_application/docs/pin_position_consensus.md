# 引脚位置校正：同元件同侧多数共识

默认在 target 格式、color 模式的 pin_lead_snap 之后启用。只校正现有引脚的法向坐标；保留编号、名称、引脚数量、器件框、导线及网络成员。未增加模型或 OCR 调用，不读取 GT。

测量使用后处理前的引脚点与当前预测框，包括边框内附近的点。每侧在原图上测量引线末端，保留 1–60 px 读数，以 ±3 px 聚类。至少三个间隔超过 6 px 的不同引脚行且覆盖该侧过半数时，使用最大支持簇的中位数；单点位移最多 25 px。证据不足时保留原流程结果。不同侧分别估计，顶部/底部单脚不会借用左右侧长度。

设置 `PCB_PIN_SIDE_CONSENSUS=0` 可回退原坐标后处理；`PCB_PIN_LEAD_PX=off` 或非 color 模式沿用已有关闭逻辑。

每例证据写入 `logs/<case>_pin_side_consensus.json`，包括逐侧测量、是否采信与变更前后坐标；decision log 的 `pin_side_consensus` 记录是否启用和修改数量。审计以每次调用的局部对象传递，不使用跨例共享的函数属性。

长度一致性是软约束。框存在系统误差、同侧具有特殊长短引脚、彩色标记或相邻图形影响扫描时，仍可能误判；本功能不用于删除候选或自动补编号。独立合成测试覆盖多数共识、重复行、少数支持、双侧不同长度、位移上限及入口开关。
