# 数值电源文字与接点恢复

配置：connectivity_recovery_v1.json / structural.patterns.numeric_power_caption。
已有单接点电源模型、唯一高置信源端点、真实红色T形电源帽、向外连续红线连接绿线，
以及同一局部蓝字至少3个高置信OCR视图一致，才补出电压名和电源接点。
支持显式数值电压文字，例如+5V、-12V、+3.3V；不把S猜成5，不从芯片VCC脚名推断电压。
已有电源接点保留。正负号或电压冲突时暂缓。重复同一视图不重复计票。

源OCR未读到电源文字时，围绕电源检测框提取蓝色字形，根据长轴优先旋转，
按3/5/4倍尺度做本地识别；所有读取共享maximum_caption_views预算。
IC、开关和连接器引脚记录仍受保护，相关文字、接点及挂网按原子候选提交。

发布前验证：375项测试通过；第二页新本地5次OCR后连通指标100%，
16个IC端口关系无缺失或新增误接；13页缓存中仅第二页改变，其余12页完整一致。
第一页、第二页完整批处理缓存入口通过。未重跑整页模型，无外部API调用。
