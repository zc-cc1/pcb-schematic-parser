# 第 11 页连通恢复（v17）

## 原因

当前 v16 的实际本地 OCR 结果中，第 11 页连通评分为 0.819047619：合并全局电源/地后，10 个参考网组仅 5 组成员完全一致。导线几何已经为 24 TP、0 FP、0 FN，但这不能说明所有元件身份与电气成员均正确。

1. YOLO 的一个 LED1 检测框包住两只横向、阴极朝左的 LED，原拆分只处理竖向三角形。LED1 接点偏到相邻行，LED2 没有独立身份。
2. SW1 没有模型元件框；其四个印刷编号被遗漏或误用到附近电阻，R1 导出成 pin_2/pin_4。
3. U1.6 错留在 LED 网，U1.8 没有入网。
4. 两只 LED 的地符号重叠在同一模型地符号框中，其末端红色条还与下方 VDD 导线相触。仅按整幅彩色连通块会错误短接，必须先识别地符号的端口。
5. 开关下方地引线未被加入网络。

## 图像和文字证据驱动的局部修复

新增 `local_symbol_contacts.py`，在既有导线几何修正后执行，只改已证实符号、引脚和网络成员，保留所有已有导线坐标。

- 横向 LED：要求高置信度源 LED 框、至少两个闭合三角区域、两条竖向极性边界、2–4 条平行红色引线、两侧实测绿色接点以及各自至少两视图的外部 LED 设计编号。内部空腔宽度还必须支持阴极在左；反向或模糊情况保留原结果。型号只在各设计编号附近确有多视图文字时补充，不由编号顺序或同组第一只元件推断。
- 四触点开关：多视图 SW/S 设计编号、两根长竖线、两个空心触点、浮动端子灰色端点共同确认形状。四个编号逐一旋转裁剪 OCR，各需两尺度高置信度一致，且四个数字唯一；任何缺失、冲突或超预算均不补开关。本页实际读取 2、4、1、3，置信度均大于 0.9999。未按数字排列推断编号。
- 电阻：仅针对已有编号超出两端器件范围的情况，重新验证独立矩形及对称外露引线，再恢复两端接点；不改变 IC 引脚数据。
- 接地：横向地梳须有源地符号框、三条间距合理的垂直红条以及连续的接入红线。源检测框覆盖两处地符号时保留该身份，并明确导出两个有图像证据的接点。开关下方地梳另需三条递减长度横条及连续引线。
- 网络：裁去元件本体和红色框边残留，保留本体外邻近的绿色导线；白色间隙不补，只允许短小蓝字覆盖处恢复连续性。地梳接点单独约束，避免把压在其他导线上的地符号笔画当成短路。只重建受修复符号影响的局部成员，清除已经失效的旧引脚引用。

运行时校验当前图像 SHA、尺寸、原点和预测证据标记；限制符号组数与 OCR 次数；保留既有 IC/开关/端子数据，禁止丢失已导出的受保护成员，禁止增删已有导线几何。证据不全时不执行该局部修复。无页码、固定原图坐标、指定元件设计编号或参考标注读取。

507 项测试通过。13 页缓存最终流程均重复执行一致，其他 12 页预测完全不变；完整导出入口与实际本地 OCR 另行核对。所有预测先冻结，再独立读取公开标注评分。整图模型输出全部复用，无新增整图模型推理或外部接口调用。

本次将第 11 页的连通与导线评分修到当前公开样本的满分；源检测框仍把两处地符号合在一个元件身份中，因此元件项仍有 1 个 FN，综合分不为 100%。普通两端元件在混合顶点连通评分中按身份统计，这个分数也不等于每种物理端口属性均已通过独立器件库验证。
