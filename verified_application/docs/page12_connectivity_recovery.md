# 第 12 页连通恢复（v18）

## 原因与修复

v17 的第 12 页连通评分为 87.7922%，12 个逻辑网组中 8 个完全匹配。导线为 28 TP、0 FP、0 FN：漏项来自网络成员，而非导线线段。

| 缺失关系 | 原因 | 修复依据 |
|---|---|---|
| C3 / R1 / U1.3 / VOUT | VOUT 已有元件身份，但没有接点 | 五边箭头边界、外露红色引线、实测红色连接点 |
| C2 / LED1 / VIN_2 | 旧规则不处理旋转的 VIN | 源检测框、旋转箭头形状、多视图 VIN 文字、引线末端 |
| R2 / LED1 | R2 只导出一只引脚；另一端位于 LED 引线拐角 | 独立电阻矩形、对称引线、已有端点一致、另一端与唯一 LED 引脚重合 |
| R3 / VIN_4 | 旋转 VIN 的身份和引脚遗漏 | 同上，并在局部匹配已有 R3 引脚 |

另找回悬空 VIN_3 的身份和灰色端点。它与右侧电路之间有白色间隙，保持断开，不添加网络。

## 通用逻辑

新增 `src/pcb_parser/oriented_port_contacts.py`，在既有结构恢复、导线几何和局部符号修正后运行。

- 端口须有当前图像的源检测框；检测置信度至少 0.45。红色内边界须为凸五边箭头、长宽比 1.6–5，只有一端为尖顶。允许 3 像素栅格边角误差和检测框外 12 像素余量。
- 相邻文字须达到 0.98 置信度并在至少两个视图一致；检测置信度低于 0.7 时需三个视图。文字不能是常见元件设计编号。旋转形状和文字位置共同确定轴向。
- 从符号边框沿轴向跟踪连续彩色引线，止于红色连接点、绿色过渡、实测拐角或小灰色悬空端点；不跨白色间隙。存在多个候选端点时不补。
- 复用已有物理端口身份与引脚；只给无引脚身份补接点，或为新物理符号建立身份。同名普通端口保持分离，不按 VIN 字样全局短接。图中没有印刷重复端口编号，`_2` 等后缀只是输出命名空间：保留已有键，对新增重复项按从右到左、同列从上到下分配，不宣称 OCR 读到了这些后缀。
- 电阻补端须重新证明矩形和对称引线；已有端点距对应实测端点不超过 5 像素，另一端须与唯一 LED 引脚在 6 像素内。保留有效编号顺序；重复运行时用同一几何证据校正两端，避免旧几何阶段再次偏移。
- 只向唯一相邻既有网络补新接点：与已有引脚在 6 像素内，或与导线端点在 12 像素内，并逐点验证中间连续彩色像素。多个候选网络时不执行；没有网络但存在直接相接引脚时建立无导线边的局部网。不得用整幅彩色连通块合网，否则没有连接点的交叉线会被短接。
- 对已证明重合的电阻/LED 接点，早期阶段可能重建约 5 像素的冗余边。只在该网恰为这两个成员、边长不超过 8 像素、整条边落在接点 4 像素邻域且有连续彩色证据时去掉；超出接点邻域的导线保留。记录被移除的边以供审计。
- 校验图像 SHA、尺寸、坐标原点和预测证据标记；限制恢复数量，超预算原子回退。保护已有 IC/开关/端子及其引脚和成员。除上述接点内冗余边外，保留已有导线坐标。

运行时不读公开标注，无页码、固定原图坐标、指定设计编号或参考网络。公开标注只用于冻结输出后的独立评分。
