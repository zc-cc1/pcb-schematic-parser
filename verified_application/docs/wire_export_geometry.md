# 最终导线几何校正

入口：agent.finalize_connectivity_recovery 完成电气修复后，调用wire_export_geometry.refine_wire_geometry。
配置：connectivity_recovery_v1.json / wire_geometry；主开关enabled，子开关source_path_turns、
observed_junction_splits、collinear_cleanup、suppress_short_ground_stubs、suppress_red_terminal_leads，
默认修改预算512。

只调整同一原网络内的edges；元件、引脚、原网ID、hyperGraph及其他字段均逐一保持不变。
证据绑定当前PNG哈希、尺寸和左上坐标模型图。无参考答案、页号、元件位号或固定坐标规则。

1. 原图红色圆点具有至少两个绿色方向支持时，长线在结点投影处分段；不把没有红点的交叉变成连接。
2. 对原直线缺乏图像支持、且原路径有明显转折偏离的情况，从同名保留模型网络恢复唯一原始折线路径；
   原始polyline方向先按source/target几何对齐，再验证像素实际连通和路径避开元件本体。
   很小的骨架抖动、相近的替代路径、白色断线及源证据不完整时暂缓。
3. 同一原网中，只合并真实共线、度数为2、偏差很小的邻段；保留红色结点，禁止把长直线接短直角拉成斜线。
   通常要求实际墨迹连通。无圆点交叉处，须有四向绿线和模型已经分开的同向虚拟分支证据，
   才允许沿原有直行分支合并；横纵网络成员始终不变。同原网近重合重复段可去重。

4. 对仅含一个元件引脚和一个GND符号的单边短网，若一端与该元件引脚重合、另一端贴近GND边框，
   则保留逻辑网络成员并省略该短GND引线的独立几何边。多边网络、长线和其他类型符号均不触发。
5. 对仍留在导出图中的接地符号短分支，要求GND引脚贴近线段端点、恰有一个其他引脚落在线段上、
   线长不超过33像素，并且沿线红色支持率至少95%、绿色支持率不超过10%，才省略该独立边。
   原网络成员及其他边不变。绿色主导的真实导线会保留；引脚坐标重叠的歧义分支也会保留。
6. 对电容、二极管、LED、电压符号、盒状元件、双向网络符号和接地符号的端点，若短段不超过33像素、
   端点与引脚距离不超过3.5像素、沿线红色支持率至少95%且绿色支持率不超过25%，
   则把这段视为符号引线，保留逻辑成员但不导出为独立导线边。电阻和电感的红色引线不应用此规则，
   因为相同形态在已验证样本中可能是真实导线段。

当前原始流水线保持兼容，最终导出用保留路径校正旧清理阶段留下的斜线与分段问题。
审计记录保存在connectivity_recovery日志的wire_geometry中。

验证：暂存组合测试489项通过。相对上一版，第一页导线TP/FP/FN从115/14/1变为115/13/1，
F1从93.88%升至94.26%，总分从97.318升至97.356；第9、11页各减少1条误报。13页相同证据
缓存逐页对照仅第1、9、11页各少一条短边，其余10页输出逐字段相同；元件、引脚、网络成员和
连通均无变化。前5页完整缓存导出入口及第一页实际本地OCR复核通过。未重跑整页模型，
无外部API。
