# 第 13 页连通恢复（v19）

## 原因

v18：连通得分 88.3436%，10 个逻辑网组中 5 个完全匹配，4 个部分匹配、1 个没有匹配；导线 47 TP / 0 FP / 2 FN。

| 受影响关系 | 漏检原因 | 图像验证后的处理 |
|---|---|---|
| C4—L1/U1.1、C4—U1.2 | C4 没有源引脚候选；旧算法从近方形框及附近横线推断了错误轴向，C4 还误入 R5/U1.3 网 | 两根互不相连的竖向红色极板确定水平方向；两侧外露线迹确认接点，移除错误归属并接入正确两侧 |
| VOUT—输出网 | 红色结点边缘把支路切成单成员图组；重建时丢弃了该组 | 验证源 T 形电源、连续外露线和实测红点，补回成员及缺失的绿色短支路 |
| 地网—U1.4 / GND | 两处支路同样被切成单成员图组；后续导线合并只有旧成员可汇集 | 从已有引脚到唯一邻近导出线段逐点检查真实像素连通，补回成员；不移动 IC 引脚 |
| 地网—C3 下端 | C3 下端分支有绿色线迹，但没有形成可导出的双成员网组 | 沿电容外侧直线走到实测红点，确认与已有地网相接，补成员及遗漏直边 |

“导线几何已合并”不代表网络成员已完整。此页的主要缺失在导出门槛及接点绑定。

## 通用代码

1. `capacitor_plate_axis.py`：源电容记录需有实际设计编号，检测置信度至少 0.55。形态学要求两根平行、近等长、间距合理的红色极板；局部红色连通域还必须互不相连，避免将矩形边框当电容。只有唯一轴向通过时才覆盖旧框/源点推断；两侧引脚仍需既有连续引线证据。该轴向证据接入 `StructuralDraft.terminal_pair`，避免下一次运行再恢复成错误方向。
2. `observed_terminal_memberships.py`：在既有最终导出修正后执行。仅处理未入网接点，并保留已有网络分组。到已有线段投影不超过 12 像素、或到另一实体引脚不超过 8 像素时，要求局部真实彩色像素连通；两个网络候选距离差不足 3 像素时暂缓。候选处若有四向绿色线迹，必须另有实测红点，防止仅一条交叉线被导出时仍错误接入。显式 NC 不参与。
3. 对更远的端点，只允许已证明的电容极板轴向或源 T 电源外露方向；96 像素内必须遇到第一处同轴实测红色连接点，中间彩色像素连续，且不能穿过其他元件本体。电容至少 8 个绿色采样点；T 电源至少 5 个。无红点交叉、白色间隙和歧义不补。
4. 只在红点附近唯一匹配已有网络时增加成员。若真实直线支路尚未被已有几何覆盖，可从首个绿色位置到红点补一条边；已有线段的坐标不变，不使用全图彩色连通块合网。
5. 校验图像 SHA、尺寸、坐标原点、预测证据标记；轴向更正、接点和新边均有预算，超预算原子回退。保护所有元件身份和既有 IC/开关/端子引脚。审计记录源极板、接点、红点、绿色支持及新增边。

运行时不读公开标注，不含页码、指定元件设计编号或固定原图坐标。上述阈值是通用几何限制，仍需新图验证其适用范围。
