# 电容身份补读与接地端点归属

配置开关：structural.patterns.unidentified_capacitor_identity / ground_owner_arbitration。
两项都依赖 colored_wire_network，整个身份、端点、连通修改由同一个原子规则提交。

电容必须有高置信检测、唯一归属的两端候选、两条等长平行红色极板、向绿线连续的引线。
只对未命名且未导出的电容，在检测框上方裁剪文字，以保留深蓝色和绿线混色笔画的掩码读取。
3倍和5倍OCR必须各自明确读到同一C数字位号且置信度>=0.98。
不从容量、编号顺序、芯片模型或参考答案推断身份。位号冲突、弱文字、白色断线均暂缓。
保留源端点空间编号；源号码属于既有工程约定，无源对称器件的极性不由此证明。

接地仲裁仅用于已导出GND但没有引脚的元件。端点必须是高置信ambiguous_owner，候选含该GND，
其他竞争框必须都是未命名、未导出、检测置信度至少低0.05的电容。
必须观察到三条对齐且由端点向内依次缩短的红杠、连续向外通往绿线的导线，以及至少两个>=0.98的GND文字视图。
不接管已经assigned给其他元件的引脚。源模型文档不改写，原始归属冲突及排除依据保留在审计中。

两个规则没有页码、元件编号或固定坐标分支。局部OCR共享maximum_caption_views预算，默认8。
IC、开关和连接器的元件与引脚记录保持保护。

第三页实测：新增电容文字2次本地OCR，加原有VCC补读4次，共6次；连通91.6291%->100%，
7/7逻辑网完整匹配；总分95.2462->99.2130；导线F1 87.64%->92.13%；6个IC脚不变。
393项测试通过。13页采用相同已冻结OCR观察做对照，仅第三页输出改变；其他页未进行新局部OCR全量验证。
前三页复用历史模型/OCR运行完整导出入口通过。未重跑整页模型，无外部API请求。
